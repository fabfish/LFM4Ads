（provenance 见各 run json `selection.endpoint`。）

## 3. 判定（登记枚举，2 seed 筛选口径）

### 3.1 baseline win（T vs S）：INCONCLUSIVE，方向证据偏负

- Δ_T(s0) 两 seed 异号（−0.0025 / +0.0002）→ 不满足 §6.1 的「全正」或「全负」→ **INCONCLUSIVE**
- 保护端点 Δ_T(macro) 2/2 负（均值 −0.0041，越过筛选地板 0.0011）→ 登记为**负向相关性**
- **结论**：纯 task-state 隔离在 s0 上无益，macro 上明确有害。Stage 1 gate 的 `Δ_T(s0)>0`
  条件不满足 → **不扩 Stage 2 的 baseline 维度**。

### 3.2 AdaTask win-case（A vs T）：s0 未越地板（不 PASS），macro 越地板（正向相关性）

- Δ_A(s0) 2/2 正（均值 +0.0005），但 `0.000528 < floor_A_s0=0.000832` → **未越地板**，且不足 4 seed → 不构成 win
- Δ_A(macro) 2/2 正（均值 +0.0044），越过筛选地板 0.0023 → 登记为**正向相关性**
- clip_dominated=False（clip_rate 均值 0.008，远低于 0.3）→ 无 clip 主导
- **结论**：AdaTask 相对 T 在 s0 只有微弱正向（低于噪声地板），但在 macro 上有越地板的正向。
  不满足预注册 §5 的「Δ_T(s0)>0 且 Δ_A(s0)>0」双条件 → **不扩 Stage 2**。

### 3.3 综合判定

`baseline win = INCONCLUSIVE（偏负）`；`AdaTask win-case = 未越 s0 地板，不 PASS`。
Stage 1 结论：**不进入 Stage 2（不扩 seeds 303/404）**。

## 4. 机制解释与可检验预测

### 4.1 观察到的相关性（非因果，因仅 2 seed）

三臂 s0 链条：S 0.7118 → T 0.7094（−0.0025）→ A 0.7098（+0.0005）。
T 的损害（相对 S）远大于 A 的修复（相对 T）。而 macro 链条相反：
T −0.0041，A +0.0044（A macro 0.7379 甚至超过 S 0.7370）。

### 4.2 机制假设

AdaTask 因子的方向设计是 **suppress s0 / amplify rest**（s0 的 AU 长期更大 → f_s0<1；
见审计 `mean_f_target≈0.89` vs `mean_f_rest≈1.2`）。因此因子天然倾向于：
- 压制梯度尺度大的目标场景 s0（弱化其对 expert 方向的主导），
- 放大梯度尺度小的 rest 场景（提升其 macro 贡献）。

这解释了「macro 大幅正、s0 微正」的拆分：**AdaTask 的收益被 rest 场景吸收，
而非目标场景 s0**。s0 仅从「task-state 隔离的损害」中被 AdaTask 部分修复。

### 4.3 可检验预测（下一实验如何证伪）

1. 若把目标场景改为 rest 中的某一小场景（而非 s0），预测 Δ_A 在该小场景上也会很小、
   Δ_A(macro) 仍偏正——即「AdaTask 始终偏袒被 suppress 的一方」，与目标场景选择无关。
2. 若把因子方向翻转（encourage s0 / suppress rest，即 `f ∝ AU`），预测 Δ_A(s0) 转正且量级增大，
   Δ_A(macro) 转负或趋零——可直接检验「方向即收益分配」的假设。
3. 若关闭 task-state 隔离（A 直接对比 S 而非 T），预测 A−S 在 s0 上仍为负
   （因为 A 继承 T 的 s0 损害），除非增大 α 使 s0 不被过度压制。

## 5. 与 F1 / site B 证据的关系

- **证实 F1 复审判断**：F1 短训的纯 task-state 乐观信号（+0.0209/+0.0420）在全数据下
  不复现（本实验 T vs S 在 s0 为 −0.0025/+0.0002）。子采样口径确会误导方向。
- **不否定 site B 的 −0.0091**：site B 是完整角色隔离 bundle（多变量），本实验是纯
  task-state（唯一变量）。两者都指向「状态隔离类在 s0/macro 无益」，但机制不同，
  不得合并为同一因果断言。
- **历史 AdaTask 结论**（1K 单 seed 旧架构）与本文不冲突也不互证：本文首次在 27K、
  真 task-axis、post-preconditioner 下测出「macro 正、s0 微正」的拆分。

## 6. 后续 backlog（按优先级）

1. **若继续 AdaTask 线**：翻转因子方向（encourage s0）做对照，检验 §4.3 预测 2；
