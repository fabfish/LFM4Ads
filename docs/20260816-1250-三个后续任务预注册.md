## E8：pooled loss + MoE 组合验证（数据已具备，只判定）

### 动机

E7 主实验用 balanced loss 得到 MoE 稳定胜出（4/4 seed），但同时发现 **balanced loss 本身
让两臂的绝对 macro 掉 ~0.004（4/4 负）**。因此最实用的组合可能是 **pooled loss + MoE**
（绝对 macro 最高），但它在 pooled 端点下相对 dense 的优势是否稳定，尚未正式判定。

### 判定（数据已在 `cache/macro_auc_27k/run_s1_*pooled*`，4 seed 齐全，无需新 run）

```
Δ_pooled(seed) = macro_test(moe+pooled) − macro_test(dense+pooled)
```

| seed | dense+pooled | moe+pooled | Δ |
|---|---|---|---|
| 42 | 0.734496 | 0.736062 | +0.001566 |
| 123 | 0.733585 | 0.732641 | −0.000945 |
| 456 | 0.734498 | 0.737058 | +0.002560 |
| 789 | 0.734746 | 0.736977 | +0.002231 |

- 均值 **+0.00135**，3/4 正、1 负（s123 −0.0009，在地板内）。

### 判定规则（冻结）

| 判定 | 条件 |
|---|---|
| **PASS** | 4/4 seed Δ>0 且 mean > 0.00135 |
| **INCONCLUSIVE** | 跨 seed 变号（当前状态）→ 允许按原口径扩 seed，不改端点/阈值 |
| **FAIL** | 4/4 seed Δ<0 |

### 预期产出

- 若 INCONCLUSIVE：如实登记"pooled 下 MoE 收益不稳定"，补 seed 456 之外的 2 个新 seed
  （预注册 seeds {101, 202}，同卡配对），扩到 6 seed 再看。
- 同时报告：绝对 macro 排序 = moe+pooled(0.7357) > dense+pooled(0.7343) >
  moe+balanced(0.7323) > dense+balanced(0.7304)。这本身就是结论的一部分。

## E9：隔离粒度 K 扫描（容量恒定）

### 设计

`Linear(330,330)` 拆成 K 个 `Linear(330,330/K)`，总参数守恒（差 45K 个 router 参数）。
扫 K ∈ {2,3,6,10,11}（加上 E7 已有的 K=5）。**只变隔离粒度，不变容量**。

| 项 | 值 |
|---|---|
| arch | moe，balanced loss（与 E7 主实验同口径，保证可比） |
| K | 2, 3, 6, 10, 11 |
| seed | 42, 123, 456, 789 |
| run 数 | 5 × 4 = 20 |
| 对照 | dense+balanced（E7 已有，4 seed） |

### 判定（冻结）

对每个 K 算 Δ_K(seed) = moe(K) − dense，同 seed 配对。
- 报告各 K 的 mean Δ 与"正向 seed 数"。
- **选出最优 K** = mean Δ 最大且 ≥2/4 正的那个；若多个并列取隔离粒度更小（更省）的。
- 结论登记为"K 的单调性证据"，不强行外推到未测 K。

### 预期

若隔离确实是收益来源，K 应在某个中间值（5~6）达到峰值，两端（2、11）回落。

## E10：真实稀疏化 top_k（激活稀疏，参数仍守恒）

### 动机

E7 的 MoE 是软路由（每个样本 5 个专家全激活）。真实 MoE 用 top-k 稀疏（每样本只激活 k 个），
省算力。1K 上曾测得稀疏化代价 ≈ −0.001；现在要测：在 27K 的隔离收益（+0.0019）基础上，
稀疏化的代价能否被覆盖。

### 代码改动

`model.CrossExpertLayer` 加 `top_k` 参数：`gate = softmax*K` 后取 top-k，其余置 0
（被关闭专家的输出恒 0、无梯度，权重仍在——**激活稀疏而非参数稀疏，参数量仍守恒**）。
`main_macro_auc.py` 加 `--top-k`，`DCNv2MoE` 透传。

### 设计

| 项 | 值 |
|---|---|
| arch | moe，K=5，balanced loss |
| top_k | 2, 3（=5 是软路由全激活，E7 已有） |
| seed | 42, 123, 456, 789 |
| run 数 | 2 × 4 = 8 |
| 对照 | dense+balanced（E7）、moe K=5 软路由（E7） |

### 判定（冻结）

```
Δ_sparse(seed) = macro_test(moe top_k=k) − macro_test(dense)
```

- 若 top_k=k 的 mean Δ 仍 > 0.00135 且 ≥3/4 正 → **稀疏化未吃掉收益**，稀疏版可用；
- 若 mean Δ 落入 (−0.00135, 0.00135) → 稀疏化代价约等于隔离收益，净效应打平；
- 若 < −0.00135 → 稀疏化代价 > 隔离收益，稀疏版不可用（与 1K 结论一致）。
- 附算力指标：稀疏化后 wall/epoch 相对软路由的下降倍数。
