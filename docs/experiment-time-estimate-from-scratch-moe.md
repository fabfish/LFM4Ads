# 从零预训练与子任务调制实验 预计耗时估算

> 创建时间：2026-08-10
> 用途：在正式执行前，对每个实验的单种子耗时给出范围估计，便于排期。
> 状态：估算稿，待「单 epoch 计时探针」校准（见末尾）。

## 估算依据（已核实）

- 数据集：KuaiRand-1K，`dataset.feather` 共 11,713,045 行。
  - 训练集 `date < 20220503`：9,281,007 行
  - 验证集 `20220503 <= date < 20220506`：1,230,368 行
  - 测试集 `date >= 20220506`：1,201,670 行
- 训练批大小：10,000（代码固定）。
  - 每 epoch 训练 batch 数 = 929
  - 每 epoch 验证评估 batch 数 = 123（每个 epoch 末尾都做一次 `evaluate(valid_set)`）
- 停止准则：训练循环 `while True`，当验证 AUC 连续一轮提升不足 0.001 即停止（早停）。
  - 从零训练收敛所需 epoch 数未知，按既有经验取 30–60 epoch 量级估算。
- 单 batch 耗时：取决于 GPU，**当前未实测**。下面用「经验区间」表达，必须靠探针校准。

## 排期口径（两种资源假设）

> 此前约定：两个 GPU 不间断串行排满（cuda:0 跑全路由+基准，cuda:1 跑部分路由加共享）。

### 假设 A：2 张 GPU 并行排满

- 预训练阶段：cuda:0 = E1(全路由) + E3(基准) ≈ 1.5+1.0 = 2.5h；cuda:1 = E2(部分路由加共享) ≈ 2.0–3.5h。
  - **墙钟 ≈ 2.0–3.5 小时**（取两者较大值）。
- 子任务调制阶段：10 个 M 实验，总算力 ≈ 10 × 0.75h = 7.5h，分到 2 张卡。
  - **墙钟 ≈ 3.5–5.0 小时**。
- 核心 1 种子总计（含预训练+调制）：**墙钟 ≈ 5.5–8.5 小时**（2 GPU）。

### 假设 B：1 张 GPU 串行

- 预训练 3 个 + 调制 10 个 = 13 实验。
- 总算力 ≈ (1.5+2.75+1.15) + 10×0.75 ≈ 5.4 + 7.5 = **12.9 小时墙钟**。

## 关键不确定性与校准方法

1. **单 batch 耗时未实测**：上面所有数字都依赖「单 epoch ≈ 30–60 epoch 收敛 × 929 batch × 单 batch 耗时」。
2. **校准动作（需批准后执行，约 1–2 分钟）**：对任意一个模型跑 1 个 epoch，记录 wall-clock，反推单 batch 耗时，再乘以「估计 epoch 数」得到精确估算。
3. **收敛 epoch 数**：从零训练若在 20 epoch 内就停，则上述时间砍半；若需 80+ epoch，则翻倍。
