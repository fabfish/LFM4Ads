## 〇、术语与度量定义

| 术语 | 定义 |
|---|---|
| **任务（task）** | = 场景 `tab`，取值 0–13，联合训练中每个 batch 混合多个场景。 |
| **优化器状态** | 每个可训练参数的一阶矩 `m` 与二阶矩 `v`（Adam 风格）。 |
| **共享状态（shared）** | 所有场景共用一份 `m/v`，先把场景梯度平均再进 AdamW。 |
| **每场景独立状态（decoupled）** | 每个场景维护自己的 `m[t]/v[t]`，方向按场景独立计算后平均。 |
| **共享 base + 残差（base+delta）** | 二阶矩分解为 `v_base`（所有场景共享）+ `v_delta[t]`（每场景残差）。 |
| 其余（macro AUC / 配对差 / 噪声地板） | 见[突破归因 §0](./20260817-1208-突破归因-公平比较下的正面结果.md)。 |

### 四方法在本项目语义下的映射（关键）

| 用户点名的方法 | 文献 | 本项目实现 | 状态 |
|---|---|---|---|
| **DualOptim** | 机器遗忘双优化器（2504.15827） | `task_state_uniform`：每场景独立 `m/v`，统一角色 lr | site B 已实现，复用 |
| **DualOptim+** | 共享 base + 解耦 delta（2605.21539, ICML 2026） | `dual_optim_plus`：`v_base`(共享) + `v_delta[t]`(残差)，`m[t]` 独立 | **site A 新增（本实验）** |
| **SkewAdam** | MoE 分层状态分配（2607.19058） | `role_isolated`：按角色差异化 lr（expert 1.0×/router 0.05×/shared 1.0×），router 无动量 | site B 已实现，复用 |
| **EWC** | 弹性权重巩固（1612.00796） | 顺序场景训练 + Fisher 正则 | **F2 独立实验，不在本矩阵** |

> DualOptim/DualOptim+ 原设定是机器遗忘（forget/retain 双目标）；本项目无遗忘语义，故按 site B 预注册 §2.3 的"只采用'不同目标不污染彼此动量'原则"映射到多场景联合训练。DualOptim+ 的 base+delta 是实现层面的机制映射，非逐行复刻官方（官方针对双目标 + 负残差取绝对值；本项目多场景下残差用平方定义、恒非负）。

## 一、要回答的问题

在 27K + 轻量 MoE(K=5, top_k=2) 联合训练下，**优化器状态分配方式（共享 / 每场景独立 / 共享 base+残差 / 角色分层）对 macro AUC 的相对效果是多少？** 为后续 adatask 提升（状态隔离的增量）与 scaling up（base+delta 省内存）提供基线。

## 二、设计：4 臂，唯一变量 = 优化器状态分配方式

| 臂 | optimizer_mode | 状态分配 | 角色 lr | 实现 |
|---|---|---|---|---|
| **B0（对照）** | `shared_adamw` | 共享 | 统一 | `SharedAdamWBatchOptimizer` |
| **B1 DualOptim** | `task_state_uniform` | 每场景独立 | 统一 | `TaskRoleOptimizer`（Batched） |
| **B2 DualOptim+** | `dual_optim_plus` | base+delta | 统一 | `DualOptimPlusOptimizer`（新增） |
| **B3 SkewAdam** | `role_isolated` | 每场景独立 | 角色差异化 | `TaskRoleOptimizer`（Batched） |

- **架构、数据、loss、lr、seed 完全一致**；唯一变量 = 优化器状态分配方式（B0–B2）或角色 lr（B3）。
- 统一口径：27K、轻量 MoE（869,750 参数）、balanced loss、expert lr=5e-4、batch 10000、max_epochs 20 / patience 10、macro AUC 主端点、macro valid 精确 argmax。
- 参数量四臂**完全相同**（优化器不引入参数）。
- B1 与 B2 的区别**仅二阶矩分解方式**（`EMA(g_t²)` vs `v_base + v_delta[t]`），一阶矩都是每场景独立；B2 是 scaling up 的关键候选。

## 三、为什么这里能测 DualOptim+，而 site B 第一版"不采用"

site B 预注册 §2.4 的"不采用"理由是"二阶残差可能为负，需取绝对值"。本实现采用**平方残差定义** `v_delta[t] = EMA((g_t − g_mean)²)`，恒非负，绕开了负残差问题；且只对 dense 参数（占 99.4%）做 base+delta，row_sparse 参数（head/router，占 0.6%）沿用每场景独立。这是 baseline 测试的合理简化，已在 `DualOptimPlusOptimizer` docstring 登记。

## 四、判定规则（启动前冻结）

**探索阶段（2 seed）只报方向与量级，不作正式 PASS/FAIL**（正式判定需 4 seed + 可靠噪声地板，见 §六）。

- 主指标：test macro AUC 配对差 \(\Delta_{\text{opt}} = \mathrm{macro(opt)} - \mathrm{macro(shared\_adamw)}\)（同 seed）。
- 参考量级：E10 的 MoE-vs-dense 收益为 +0.005（macro 噪声地板 0.00135）。
- **方向登记**：每个优化器相对对照的 Δ，2 seed 是否同号、量级是否 > 0.00135（参考地板）。

**预注册的三种结局（先写死）**：

| 结局 | 含义 | 后续 |
|---|---|---|
| A：某优化器 Δ > 0 且 2 seed 同号 | 该状态分配方式有方向性收益 | 扩 4 seed 正式判定 |
| B：某优化器 Δ 在 ±0.001 内波动 | 该方式与共享 AdamW 等价（本项目规模下无差异） | 登记"无差异"，scaling up 时以内存节省为准 |
| C：某优化器 Δ < 0 且 2 seed 同号 | 该方式有害 | 登记负结论 |

**禁止**：不得因本矩阵结果改判 E10/E11 的 PASS；不得跨 site 相减；不得用 site B 短测的 valid 数字与本矩阵 test 数字做配对差。
