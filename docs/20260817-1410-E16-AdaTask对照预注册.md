## 零、术语（自包含）

| 术语 | 定义 |
|---|---|
| **AdaTask** | 原义：为不同任务（本项目中"任务" = 场景 `tab`）分配**不同的有效学习率**，让被大任务梯度压过的小任务也能推进参数。 |
| **AU（accumulated squared gradient）** | 每（层, 专家, 场景）维护的梯度平方 EMA：\(\mathrm{AU} \leftarrow \beta\,\mathrm{AU} + (1-\beta)\lVert\nabla_{\theta}L_s\rVert^2\)，\(\beta=0.99\)。实现于 `model.py:225-293`（`GradientTracker`）与 `model.py:358-365`。 |
| **调制因子 f** | 由 AU 导出的标量：`encourage: (au/mean_au)^α`、`suppress: (mean_au/au)^α`，α=0.5（`model.py:402-416`）。 |
| **pre-preconditioner 调制** | 在优化器之前缩放**梯度**：`param.grad.mul_(f)` 后 `AdamW.step()`（历史实现，`model.py:450-478`）。 |
| **post-preconditioner 调制** | 在优化器之后缩放**参数更新量** \(\Delta\theta\)，或等价地用 per-param-group 的 `lr`。**这才是"per-task learning rate"的字面含义。** |
| 其余（macro AUC / 端点 / 噪声地板 / 判定枚举） | 见[归因文档 §0](./20260817-1208-突破归因-公平比较下的正面结果.md) |

## 一、先回答"能不能做"：能，但历史实现是数值空操作，必须先修

### 1.1 决定性的零成本证据：AdamW 对梯度的常数缩放完全不敏感

AdamW 的更新量（忽略 eps 与 decoupled weight decay）：

\[
\Delta\theta = -\,\mathrm{lr}\cdot\frac{m_t}{\sqrt{v_t}},\qquad
m_t=\mathrm{EMA}(g),\quad v_t=\mathrm{EMA}(g^2)
\]

若把每一步的梯度都乘同一个常数 \(c\)：\(m_t\to c\,m_t\)、\(v_t\to c^2 v_t\)，于是

\[
\frac{m_t}{\sqrt{v_t}}\ \to\ \frac{c\,m_t}{\sqrt{c^2v_t}}=\frac{m_t}{\sqrt{v_t}}\quad(\textbf{完全不变})
\]

**这是恒等式，不是近似。** 数值验证（`scripts/diagnose/diagnose_adam_scale_invariance.py`，200 步、固定梯度序列、唯一变量是缩放因子）：

| 缩放因子 f | 最终参数相对偏差 vs f=1 |
|---|---|
| 0.1 | 1.84×10⁻⁷ |
| 0.5 | **0**（逐位相同） |
| 2.0 | **0**（逐位相同） |
| 10.0 | 1.41×10⁻⁷ |
| 100.0 | 1.91×10⁻⁷ |
| 0.1 / 10.0（带 weight_decay=0.01） | 1.60×10⁻⁷ / 1.53×10⁻⁷ |

即：**梯度放大 1000 倍与不放大，训练轨迹在 float32 精度内完全一致**（偏差 ~1e-7 是浮点噪声）。

对照组——**时变**因子确实有作用：

| 时变因子 | 相对偏差 vs f≡1 |
|---|---|
| \(1+0.9\sin(t/20)\) | **0.366** |
| \(t<100\) 时 0.1，之后 10 | **0.430** |
| 线性 0.5→2.0 | 0.215 |

### 1.2 因此历史 AdaTask 结论的技术根因（新增归因）

历史实现（`model.py:450-478`）是 `param.grad.mul_(f)` → `AdamW.step()`，属 pre-preconditioner。结合 §1.1：

- 因子 \(f\) 中**恒定的那部分被 Adam 完全抵消**；
- 只有 \(f\) 的**时间变化率**能影响训练。而 \(f\) 由 AU 的 EMA（β=0.99）导出，训练进入稳态后 AU 趋稳 → \(f\) 趋于常数 → **调制趋于失效**；
- 所以历史观测到的"encourage/suppress 相对 none 都是负向、方向还反直觉"（Δ −0.0035 / −0.0008，`archive/conclusions/20260814-1522`）**更可能是 AU 早期瞬态 + 单 seed 噪声，而不是"任务自适应学习率无效"的证据**。

这与当时审计的判断一致（`archive/analysis/20260812-1723-MoE-学习率分配审计与实验计划.md:462`）：
> "当前 AdaTask 的梯度乘因子不能回答 task-specific LR 问题；应先建立 post-preconditioner block LR 与 exact task-state 上界。"

**本节的价值**：把这句定性判断升级为**定量、可复现的恒等式 + 数值证据**。也就是说——**AdaTask 这个方向在本项目里其实从未被真正测过。**

### 1.3 历史结论为什么全部不可复用（四条硬伤，逐条对照当前口径）

| 维度 | 历史 AdaTask 实验 | 当前口径 | 后果 |
|---|---|---|---|
| 数据集 | KuaiRand-**1K** | 27K | 1K 的 macro 噪声地板 0.0113 > 待测效应 → 必然 INCONCLUSIVE |
| 端点 | pooled / 8 场景均值 AUC（未走 macro 判定链） | **macro AUC**（8 场景等权，test） | 端点错配，见[归因 §3.2](./20260817-1208-突破归因-公平比较下的正面结果.md) |
| seed | **1 个**（42） | 4 个，同卡配对 | 单 seed 无法算噪声地板，判定枚举不适用 |
| 架构 | `DCNv2CapacityMoE`（K=4 full-rank + STE + lb），该路线**已关闭**（容量收益≈0） | 参数守恒的 `DCNv2MoE`(K=5, top_k=2)，已有 PASS 基线 | 载体不同，结论不可迁移 |
| 实现 | pre-preconditioner（§1.1 证明近乎空操作） | 需改 post-preconditioner | 机制未被测过 |

**结论：历史 AdaTask 的三条结论（"调制无 AUC 收益""方向反直觉""AU 冻结导致专家饿死"）中，前两条降级为"实现缺陷下的观测"，第三条（AU 冻结）是机制发现、仍然有效且对本实验构成风险（见 §3.3）。**

## 三、设计：四臂，唯一变量 = 每场景的有效学习率如何分配

### 3.1 训练循环的必要改动（与历史一致，须显式登记）

AdaTask 需要**按场景分子批次做 backward**（每个场景一次 `backward` + 一次调制 step），而当前 `main_macro_auc.py` 是整批 `backward`。这会改变优化步数与批内组成，**因此 none 臂也必须用同样的按场景切分**，否则引入第二个变量。

> 冻结决定：**四个臂全部使用"按场景子批次 backward + 每场景一次 step"**。B1/B2 的 top_k、router 对照仍用整批口径。故 E16 的 none 臂**不等于 E10**，必须自带 none 臂作为 E16 内部基线；E10 只作趋势参照，**不得与 E16 的数字做配对差**。

### 3.2 四臂

| 臂 | 有效学习率分配 | 参数量 | 说明 |
|---|---|---|---|
| **N（基线）** | 无调制（f≡1），按场景切分 backward | 869,750 | E16 内部基线，地板由它算 |
| **P（历史实现复现）** | pre-preconditioner：`grad.mul_(f)` → AdamW | 869,750 | **预期与 N 无显著差异**（§1.1）。它是**证伪哨兵**：若 P 与 N 差异超地板，说明 §1.1 的分析在真实训练中不成立，必须先解释再继续 |
| **Q（真 per-task LR，encourage）** | post-preconditioner：\(\Delta\theta \mathrel{*}= f\)，\(f=(\mathrm{au}/\overline{\mathrm{au}})^{0.5}\) | 869,750 | 给"梯度大（主导）"的场景-专家更大步长 |
| **R（真 per-task LR，suppress）** | post-preconditioner，\(f=(\overline{\mathrm{au}}/\mathrm{au})^{0.5}\) | 869,750 | 给"梯度小（被压制）"的场景-专家更大步长 —— **这才是"救小场景"的方向，是本实验的主假设臂** |

- 全部：27K、轻量、K=5、**top_k=2 硬路由**、balanced loss、lr=1e-3、α=0.5、β=0.99、4 seed 同卡配对、macro 主端点、macro valid 精确 argmax。
- **参数量四臂完全相同**（AdaTask 不引入参数）→ 严格公平，唯一变量是"每场景的有效学习率"。
- 调制范围：仅 `cross_layers[*].experts[*]`（`expert_mode`），**router 与 shared 不调制**（`router_mode=shared_mode=none`），与历史口径一致，避免同时动两处。

### 3.3 已知风险：AU 冻结 / 专家饿死（必须监测，不得事后才发现）

历史机制发现（`archive/conclusions/20260814-1522` §4.1）：**硬路由下未被选中的专家没有梯度 → 它的 AU 不更新、冻结在低值**。而 suppress 因子 \((\overline{\mathrm{au}}/\mathrm{au})^{0.5}\) 在 au→0 时**爆炸**。当前配置是 top_k=2（未选中的 3 个专家每步都无梯度），风险直接命中。

**冻结的处置规则（跑前定，不许事后打补丁）**：
1. AU 下限保护：`au = max(au, 1e-12)`，且因子上限 **clip 到 [1/3, 3]**；这两个常数写死在实现里，属实验定义的一部分。
2. 每 epoch 记录：各专家 AU 的 max/min 比、被 clip 的因子占比、专家 dispatch 分布（复用 B0 的 router 权重 dump）。
3. 若某臂出现 **>30% 的因子触到 clip 边界**，该臂结论标注"受 clip 主导"，**不得**解释为 AdaTask 机制的效果。

## 四、判定规则（启动前冻结）

主终点：**test macro AUC 的配对差**（同 seed、同 site、同卡）。噪声地板 = 2×SD(**N 臂** test macro across seeds)，由 site B 自己的 run 计算（不得用 site A 的 0.00135）。

| 判定对象 | Δ 定义 | PASS 条件 |
|---|---|---|
| **主假设**：suppress 式真 per-task LR 有增量 | \(\Delta_R = \mathrm{macro(R)} - \mathrm{macro(N)}\) | 4/4 seed 同号为正 且 均值 > 地板 |
| 反方向对照 | \(\Delta_Q = \mathrm{macro(Q)} - \mathrm{macro(N)}\) | 同上 |
| **实现哨兵** | \(\Delta_P = \mathrm{macro(P)} - \mathrm{macro(N)}\) | **预期 \(\lvert\Delta_P\rvert <\) 地板**（即"历史实现≈空操作"被真实训练证实） |

**预注册的结局表（先写死，防事后叙事）**：

| 结局 | 含义 | 处理 |
|---|---|---|
| \(\Delta_R\) PASS，\(\Delta_P\) 在地板内 | 任务自适应学习率有效，且历史实现确实是空操作 | 归档"AdaTask 在本项目无效"的旧叙事，写入新结论；下一步扫 α |
| \(\Delta_R\) 与 \(\Delta_Q\) 均 INCONCLUSIVE，\(\Delta_P\) 在地板内 | 端点/精度到位、实现已修，仍无收益 | **AdaTask 路线关闭**（这才是第一次真正有资格下这个结论） |
| \(\Delta_P\) 超地板 | §1.1 的恒等式分析在真实训练中不成立 | **停止 E16**，先解释（很可能是 AU 早期瞬态占主导），不得继续跑 Q/R |
| \(\Delta_R\) FAIL（4/4 负） | 给弱场景加步长有害 | 登记为负结论，转而检验 Q 方向 |
| 任一臂 >30% 因子触 clip | 结论受 clip 主导 | 标注后重设 clip 区间重跑该臂（**只允许一次**，且须更新本文档） |
