## 一、先回答：是的，拿到了公平比较下的正面结果

### 1.1 E11 结果：加回 5.5 亿 ID 参数后，MoE 收益依然成立

| seed | dense (551,317,475 参数) | moe top_k=2 (551,317,700) | Δ |
|---|---|---|---|
| 42 | 0.724492 | 0.731004 | **+0.006512** |
| 123 | 0.725169 | 0.728358 | **+0.003189** |
| 456 | 0.725665 | 0.728887 | **+0.003223** |
| 789 | 0.724183 | 0.728577 | **+0.004394** |

- Δ 均值 **+0.004329**，**4/4 seed 全正**，full-ID 实测噪声地板 0.001335 → 超出 **3.24 倍** → **PASS**
- 参数量差 **+225**（纯 router，0.00004%），优化器同为 dense AdamW（无 sparse、无语义差异）
- → **公平性质疑排除**：MoE 收益不是"删掉 ID 表"制造的假象。

### 1.2 顺带一个更强的负结论：那 5.5 亿 ID 参数是**有害的**

加回 ID 表的净影响（同架构配对，4/4 seed 一致为负）：

| 架构 | macro 变化 | 逐 seed |
|---|---|---|
| dense | **−0.005499** | −0.0061 −0.0044 −0.0044 −0.0070 |
| moe | **−0.006182** | −0.0048 −0.0066 −0.0054 −0.0079 |

这比 1K 上的 E1 结论更强一档：
- E1（1K）："删掉 84M ID 表，AUC **不变**" → 死重；
- E11（27K）："加回 5.5 亿 ID 表，AUC **降 0.0055**（4 倍地板）" → **有害**。

原因即预注册时的预判：ID 平均曝光 2.6 次、test 74% OOV，这些参数只能学噪声。
代价：参数 ×634、训练慢 6 倍、AUC 反降 0.0055。

## 二、突破归因：五组反事实的完整消融

**这不是一个"换了 X 就成了"的故事。** 我们手上恰好有五组反事实，可以精确归因：

| # | 数据集 | 端点 | 门控 | ID 表 | Δ_moe 均值 | 噪声地板 | 倍数 | 正向 seed | 判定 |
|---|---|---|---|---|---|---|---|---|---|
| E5 | **1K** | macro | 软路由 | 无 | −0.0047 | 0.0113 | — | 1/4（变号） | **INCONCLUSIVE** |
| E8 | 27K | **pooled** | 软路由 | 无 | +0.001353 | 0.001022 | 1.32 | 3/4 | **INCONCLUSIVE** |
| E7 | 27K | macro | **软路由** | 无 | +0.001881 | 0.001354 | 1.39 | 4/4 | **PASS（勉强）** |
| E10 | 27K | macro | **硬 top_k=2** | 无 | **+0.005012** | 0.001354 | **3.70** | 4/4 | **PASS（稳健）** |
| E11 | 27K | macro | 硬 top_k=2 | **加回 551M** | **+0.004329** | 0.001335 | **3.24** | 4/4 | **PASS** |

**读法**：
- E5 → E7 只改了数据集（1K→27K）：从变号 INCONCLUSIVE 变成 4/4 正 PASS；
- E7 → E8 只改了端点（macro→pooled）：从 4/4 正退回 3/4 正 INCONCLUSIVE；
- E7 → E10 只改了门控（软→硬）：地板倍数从 1.39 跳到 3.70；
- E10 → E11 只改了 ID 表（无→加回）：倍数 3.70→3.24，**结论稳健不变**。

## 三、逐因素归因：各自扮演什么角色

### 3.1 换数据集（1K→27K）= **必要条件，但不是充分条件**

直接回答"是因为换了数据集吗"：**是必要的，但只换数据集不够。**

- **必要性**：1K 小场景（s3/s8）test 正类仅 **70/71 个**，AUC 理论标准误 0.05，macro 噪声地板 **0.0113**。
  而我们要测的效应只有 0.005 —— **噪声比信号大 2 倍，任何方法都测不出**。
  27K 让小场景正类涨到 1618/1631（×23），地板降到 **0.00135（低 8.4 倍）**。
- **不充分**：换到 27K 之后，如果仍用 pooled 端点（E8），Δ 只有 +0.001353、3/4 正，
  **依然判 INCONCLUSIVE**。数据量解决了"尺子精度"，没解决"量错了地方"。

### 3.2 换端点（pooled→macro）= **同等必要**

- pooled AUC 里 0.6363/0.7775 是"认出这是哪个场景"白拿的（场景 CTR 差 26 倍），
  而 MoE 的收益机制（参数隔离→减少跨场景干扰）**100% 作用在场景内排序**。
- 小场景合计只占 test 0.5%（1K）——即使把 s7 从 0.43 救到 0.73，pooled 只动 0.0001。
- 实测：**macro 端点的 Δ 是 pooled 的 2–7 倍**（E7 口径对照表）。
- 这一项的独立证据就是 E8：同样 27K、同样软路由，**只换端点就退回 INCONCLUSIVE**。

### 3.3 换门控（软路由→硬 top_k=2）= **从"勉强显著"到"稳健显著"的放大器**

- 软路由（E7）：+0.001881，只有地板的 **1.39 倍** —— 统计上过关，但脆弱；
- 硬路由（E10）：+0.005012，地板的 **3.70 倍**，且 hard−soft 配对差 +0.0031、**4/4 seed 全正**。
- 机制：软路由下 5 个专家全参与、梯度互相平均，专家差异被拉平；
  硬路由**切断无关场景的梯度**（每场景只回传 2 个专家），特化彻底。
- 这一项把结论从"能发表但一碰就碎"变成"扛得住复查"。

### 3.4 删 ID 表 = **工程使能条件（不是收益来源）**

- 删掉后模型 551M→0.87M（÷634），单 epoch 从 20min 降到 3.4min（快 6 倍）；
- 这让 **4 seed × 多配置 × 多阶段**的矩阵变得可负担（E5+E7+E8+E10 共 80 run）；
- **但它不是收益来源**：E11 加回 ID 表后 MoE 收益依然 PASS（+0.0043，4/4 正）。
- 换句话说：删 ID 表让我们**跑得起实验**，不是让实验**出正结果**。

### 3.5 归因总结（一句话）

> **数据集换 27K 和端点换 macro 是两个缺一不可的必要条件（前者给够测量精度，后者对准收益作用位置），硬路由 top_k=2 把效应放大 2.7 倍使结论稳健，删 ID 表只是让实验跑得起来的工程手段。**

## 四、方法论教训（比结论本身更值钱）

1. **"没有效应"和"测不出效应"是两件事**。1K 上跑了两千块钱的实验全是 INCONCLUSIVE，
   过去被解读成"MoE 在这个任务上没用"；实际是**小场景 70 个正样本，统计上不可能测出**。
   → 新规矩：**开跑前先算噪声地板**（用 dense 臂跨 seed SD 或 Hanley-McNeil 标准误），
   若地板 > 预期效应，实验设计本身就是无效的，别花钱。

2. **主终点必须对准收益的作用位置**。pooled AUC 是"看起来最正统"的指标，
   但它对 MoE 的收益机制近乎不敏感。
   → 新规矩：**先问"这个改动的收益会出现在哪个子群/哪个维度"，再选端点**。

3. **参数占比不能推断瓶颈**。97.9% 的参数（ID 表）不仅不是瓶颈，加回来还有害。
   → 新规矩：判断瓶颈用容量对照（widened）或零成本诊断（曝光/OOV/消融），不看参数量。

4. **性能优化要先 benchmark 再动手**。本轮为加速 full-ID 写了 sparse embedding +
   SparseAdamW，实测 **dense AdamW 反而快 2.5 倍**（12.3ms vs 30.9ms），
   且 sparse 有"未访问行动量不衰减"的语义差异**无法严格对齐**，方案作废。
   → 新规矩：优化方案先跑 30 步 benchmark，再决定要不要写。

5. **公平性质疑要正面回应，不要绕开**。轻量模型上的结论天然会被问"是不是删东西删出来的"。
   花 20h 跑 full-ID 把它钉死，比在文档里解释十遍都有用。

## 五、当前最优配置与完整结论

**推荐配置**：轻量模型（去三大 ID 表，0.87M 参数）+ scenario-routed MoE(K=5, **硬路由 top_k=2**)

| 配置 | macro AUC | 参数量 |
|---|---|---|
| **轻量 + moe top_k=2** | **0.735388** ← 最优 | 869,750 |
| 轻量 + moe 软路由 | 0.732256 | 869,750 |
| 轻量 + dense | 0.730376 | 869,525 |
| full-ID + moe top_k=2 | 0.729206 | 551,317,700 |
| full-ID + dense | 0.724877 | 551,317,475 |

三层结论：
1. **MoE 有效**：Δ=+0.0050（轻量）/+0.0043（full-ID），两种规模下 4/4 seed 全正；
2. **收益来自路由**：参数守恒（+225）、优化器相同、frozen-router 哨兵 ≈0（−0.0003/+0.0001）；
3. **ID 表有害**：加回 5.5 亿参数 macro 降 0.0055，4/4 seed 负。

## 六、结论边界（登记，不得放宽）

1. 效应量级 +0.004~0.005 macro AUC（约 0.5 个百分点，相对 +0.7%），**方向可复现但绝对值小**，
   不得表述为"大幅提升"。
2. 口径限定：KuaiRand-27K、DCNv2、K=5、balanced loss、lr=1e-3、batch 10000、
   macro AUC（8 场景等权）、4 seed 同卡配对、early-stop 基于 macro valid。
3. **未验证条件计算收益**：top_k=2 是激活稀疏（5 个专家仍全算），wall 0.98x，**未省算力**。
4. **未验证专家是否真的分化**：训练后的 dispatch 分布尚未记录（见新实验计划 E12）。
5. 不跨数据集比较绝对 AUC；1K 的历史结论不外推到 27K，反之亦然。
