## 零、术语与度量定义（本章使本文自包含，读前必看）

### 0.1 数据与符号

数据集每一行是一次「曝光」，含标签 \(y\in\{0,1\}\)（是否点击）和一个**场景 id**（KuaiRand 的 `tab` 字段，取值 0–13，表示这次曝光发生在 App 的哪个板块，例如主 feed、单列页、同城页等）。场景之间样本量与点击率差异极大（1K 上：s1 占训练 65.6%、CTR 0.4366；s3 占 0.34%、CTR 0.0206，**CTR 相差 26 倍**）。

记：
- \(S\)：**主端点场景集合**，本项目固定为 `MACRO_SCENARIOS = {0,1,2,3,4,5,6,8}`，共 8 个（预注册时冻结，事后不得增删）；
- \(n^+_s, n^-_s\)：场景 \(s\) 在 test 集中的正样本数、负样本数；
- \(N^+=\sum_s n^+_s,\ N^-=\sum_s n^-_s\)：test 全体正负样本数。

### 0.2 AUC（本文所有精度数字的基础）

AUC 的**成对定义**：随机取一个正样本和一个负样本，模型给正样本更高分的概率。

\[
\mathrm{AUC}=\frac{\#\{(i,j):\ y_i=1,\ y_j=0,\ \hat p_i>\hat p_j\}}{\#\{(i,j):\ y_i=1,\ y_j=0\}}
\]

即 AUC 完全由「正负样本对（pair）中排对的比例」决定。**这一点是理解后文 §3.2 的唯一前提。**

### 0.3 两种 AUC 的严格区别：pooled 与 macro

| 名称 | 定义 | 计算方式 | 本项目角色 |
|---|---|---|---|
| **pooled AUC**（合池 AUC） | 把**所有场景的样本倒进一个池子**，在这个池子里算一次 AUC | 分母是全体 \(N^+\times N^-\) 个正负对，**其中包含"正样本来自场景 A、负样本来自场景 B"的跨场景对** | 辅助终点 |
| **macro AUC**（场景内宏平均 AUC） | 在**每个场景内部单独**算 AUC，再对 8 个场景**等权算术平均** | \(\mathrm{AUC_{macro}}=\frac{1}{\lvert S\rvert}\sum_{s\in S}\mathrm{AUC}_s\)，每个 \(\mathrm{AUC}_s\) 的分母只含**同场景**正负对 | **主终点** |

关键差别只有两条，务必分清：
1. **pooled 允许跨场景对参与打分，macro 完全排除跨场景对**；
2. **pooled 按样本量加权**（大场景主导），**macro 按场景等权**（每个场景权重恒为 1/8，与样本量无关）。

### 0.4 「端点（endpoint）」是什么

**端点 = 事先声明、用于做 PASS/FAIL 判定的那一个指标**（借用临床试验术语）。本项目：
- **主端点**：macro AUC（8 场景等权）——一切判定以它为准；
- **辅助端点**：pooled AUC——只作参考，**不参与判定**；
- **模型选择也必须用主端点**：early-stop / 选 epoch 用 macro **valid** AUC。若用 pooled valid 选 epoch、再用 macro test 报告，会重新引入错配。

所以文中「**换端点**」严格指：*把用于判定与模型选择的那个指标，从 pooled AUC 换成 macro AUC*。它**不是**换模型、换数据、换 loss——同一批预测分数可以同时算出两个端点的值。

### 0.5 噪声地板（noise floor）与判定规则

- **配对差（paired delta）**：同一 seed 下 `moe` 与 `dense` 的端点差 \(\Delta_{\text{moe}}(\text{seed})=\mathrm{AUC^{moe}}-\mathrm{AUC^{dense}}\)。同 seed、同卡、同数据切分，故不含初始化与设备的混杂。
- **噪声地板**：\(\text{floor}=2\times \mathrm{SD}\big(\mathrm{AUC^{dense}}\ \text{across seeds}\big)\)。含义：**同一个模型只换随机种子就能产生的波动幅度**。效应若小于它，无法与随机波动区分。
- **判定枚举**（跑之前冻结，跑完不得改）：
  - `PASS` = 全部 seed 的 \(\Delta\) **同号为正** **且** 均值 > 噪声地板；
  - `INCONCLUSIVE` = 上述任一条不满足（**注意：这不等于"MoE 没用"，而是"这个实验设计测不出来"**）；
  - `FAIL` = 全部 seed 同号为负且幅度超地板。
- **地板倍数** = \(\lvert\overline{\Delta}\rvert/\text{floor}\)，是本文比较各实验强弱的统一尺度。
- **哨兵（sentinel）**：`frozen-router` MoE——把 router 参数冻结在零初始化（门控恒为 1，与 dense 代数等价）。它若也出现收益，说明收益来自实现差异而非路由；实测 ≈0（−0.0003/+0.0001），故收益归因于路由成立。

## 二、突破归因：五组反事实的完整消融

**这不是一个"换了 X 就成了"的故事。** 我们手上恰好有五组反事实，可以逐因素归因。术语与判定规则见 §0。

| # | 数据集 | 判定所用端点 | 门控 | ID 表 | \(\overline{\Delta_{\text{moe}}}\)（按本行端点计） | 噪声地板（同端点） | 地板倍数 | 同号正 seed | 判定 |
|---|---|---|---|---|---|---|---|---|---|
| E5 | **1K** | macro | 软路由 | 无 | −0.0047 | 0.0113 | — | 1/4（符号不一致） | **INCONCLUSIVE** |
| E8 | 27K | **pooled** | 软路由 | 无 | +0.001353 | 0.001022 | 1.32 | 3/4 | **INCONCLUSIVE** |
| E7 | 27K | macro | **软路由** | 无 | +0.001881 | 0.001354 | 1.39 | 4/4 | **PASS** |
| E10 | 27K | macro | **硬 top_k=2** | 无 | **+0.005012** | 0.001354 | **3.70** | 4/4 | **PASS** |
| E11 | 27K | macro | 硬 top_k=2 | **加回 551M** | **+0.004329** | 0.001335 | **3.24** | 4/4 | **PASS** |

> **读表约束（务必遵守）**：Δ 列的每一行是**在该行声明的端点上**计算的，且 E5 行来自 1K、其余来自 27K。因此 **Δ 的绝对值不可跨行直接比较**；跨行唯一可比的量是「**地板倍数**」（已用各行自己的噪声地板归一）与「同号 seed 数」。

**逐步反事实（每步只有一个变量不同）**：
- E5 → E7，唯一变量 = 数据集（1K→27K）：符号不一致的 INCONCLUSIVE → 4/4 同号正的 PASS；
- E7 → E8，唯一变量 = 判定端点（macro→pooled）：4/4 同号 → 3/4 同号，退回 INCONCLUSIVE；
- E7 → E10，唯一变量 = 门控（软路由→硬路由 top_k=2）：地板倍数 1.39 → 3.70；
- E10 → E11，唯一变量 = 是否含三张高基数 ID 表（无→加回 551M 参数）：地板倍数 3.70 → 3.24，判定不变（PASS）。

## 三、逐因素归因：各自扮演什么角色

### 3.1 换数据集（1K→27K）= **必要条件，但不是充分条件**

直接回答"是因为换了数据集吗"：**是必要的，但只换数据集不够。**

- **必要性（测量精度问题）**：1K 上小场景（s3/s8）test 正类仅 **70/71 个**，按 Hanley–McNeil 公式算出的单场景 AUC 标准误约 **0.05**；8 场景等权平均后 macro 噪声地板（定义见 §0.5）实测 **0.0113**。而待测效应量级为 0.005 —— **噪声地板是效应的 2.3 倍**，按 §0.5 的判定规则，任何方法在此设计下都只能得到 `INCONCLUSIVE`。27K 使小场景 test 正类增至 1618/1631（×23），地板降至 **0.00135**（低 8.4 倍），效应首次落在地板之上。
- **不充分（测量位置问题）**：换到 27K 后若仍用 pooled 作判定端点（E8），\(\overline{\Delta}=+0.001353\)、3/4 同号，**仍判 `INCONCLUSIVE`**。即：样本量只解决"尺子刻度够不够细"，不解决"尺子量的是不是收益发生的地方"（后者见 §3.2）。

### 3.2 换端点（主终点 pooled → macro）= **同等必要**

先重申定义（详见 §0.3/§0.4）：这一步**不改模型、不改数据、不改 loss**，只改「用哪个指标做判定与选 epoch」。同一批预测分数可同时算出两个端点。

#### (a) 为什么 pooled AUC 对 MoE 的收益近乎不敏感——成对权重分解

由 §0.2，AUC 由正负对的排对比例决定。把 pooled 的全部 \(N^+N^-\) 个正负对按「两者是否同场景」划分，得到**恒等式**（无近似，忽略并列分数的约定差异）：

\[
\mathrm{AUC_{pooled}}=\rho_{\text{within}}\cdot \mathrm{AUC_{within}}+\left(1-\rho_{\text{within}}\right)\cdot \mathrm{AUC_{cross}}
\]

\[
\rho_{\text{within}}=\frac{\sum_{s} n^+_s n^-_s}{N^+N^-},\qquad
\mathrm{AUC_{within}}=\frac{\sum_s n^+_s n^-_s\,\mathrm{AUC}_s}{\sum_s n^+_s n^-_s}
\]

含义：
- \(\mathrm{AUC_{cross}}\)（跨场景对项）衡量的是「**把高 CTR 场景的样本整体排在低 CTR 场景之上**」的能力。因为场景 CTR 相差 26 倍，模型只要认出场景 id 就能把这一项做得很高——这**不需要任何 user/video 特征**。
  - 直接实测支撑：仅用「场景先验 CTR」作为唯一打分（完全不看 user/video 特征），pooled AUC = **0.6363**；而完整 dense 模型的 pooled AUC = **0.7775**、场景内 macro AUC = **0.6736**（1K，冻结基线 `dcnv2_vanilla.pt`，见 [E5 预注册 §一](./20260815-0018-场景内泛化MoE长程矩阵预注册.md)）。
  - 这就是先前文档中「白拿」一词的严格所指：**pooled AUC 的 0.6363 可由零特征的场景先验基线达到**，故 pooled 高低主要反映「区分场景」，而非「场景内排序」。**下文不再使用"白拿""一大半"这类非定量表述。**
- \(\mathrm{AUC_{within}}\)（同场景对项）是**按 \(n^+_sn^-_s\) 加权**的场景内排序质量。MoE 的收益机制（参数隔离 → 减少跨场景梯度干扰）**只作用在此项**：它改善的是每个场景内部谁排前面，不改变"哪个场景整体更容易点"这一先验。

#### (b) 代入数值：pooled 给小场景的权重比 macro 小 5 个数量级

用 1K 的场景占比 \(p_s\) 与 test CTR \(c_s\) 估算成对权重（**估算**，假设：以 train 占比近似 test 占比、\(n^+_s\propto p_sc_s\)、\(n^-_s\propto p_s(1-c_s)\)；含 s7/s12 两个辅助场景以覆盖 99.8% 样本）：

| scenario | \(p_s\) | \(c_s\) | pooled 中的成对权重 \(\dfrac{n^+_sn^-_s}{\sum_t n^+_tn^-_t}\) | macro 中的权重 |
|---|---|---|---|---|
| 1 | 65.63% | 0.4366 | **45.7%** | 12.5% |
| 0 | 20.79% | 0.1167 | 1.92% | 12.5% |
| 4 | 7.60% | 0.5436 | 0.62% | 12.5% |
| 2 | 3.50% | 0.3690 | 0.12% | 12.5% |
| 6 | 1.53% | 0.1468 | 0.013% | 12.5% |
| 3 | 0.34% | 0.0206 | **1.0×10⁻⁴ %** | 12.5% |
| 5 | 0.14% | 0.2008 | **1.3×10⁻⁴ %** | 12.5% |
| 8 | 0.15% | 0.0344 | **3.2×10⁻⁵ %** | 12.5% |
| *(同场景对合计 \(\rho_{\text{within}}\))* | | | **≈ 48%**（跨场景对 ≈ 52%） | 100% |

两条可验算的结论：
1. **pooled 内部，s1 一个场景就独占 45.7% 的同场景对权重**（占全部正负对的 45.7%），而 macro 给它 12.5%。pooled 事实上是"s1 的场景内 AUC + 场景识别能力"的混合物。
2. **三个小场景 s3/s5/s8 在 pooled 中的权重合计 ≈ 2.7×10⁻⁶（即 0.00027%），在 macro 中合计 37.5%——相差约 1.4×10⁵ 倍。**

#### (c) 灵敏度：小场景改善能在 pooled 上产生多大位移

设某小场景内部 AUC 提升 \(\delta\)，其在 pooled 中的成对权重为 \(w\)，则**经同场景对通道**的 pooled 位移为 \(w\cdot\delta\)。以 1K 的 s7（\(w\approx 9.5\times10^{-8}\)）为例，把它从 0.4268（低于随机，即预测方向是反的）救到 0.73（\(\delta\approx0.30\)）：

\[
\Delta \mathrm{AUC_{pooled}}\approx 9.5\times10^{-8}\times0.30\approx 3\times10^{-8}
\]

而 macro 端点上同一改善的位移是 \(\delta/8\approx0.0375\)（若 s7 在主场景集合内）。

> 口径说明：历史文档（E5 预注册 §1）对同一现象给的是 \(\sim1\times10^{-4}\) 的宽松量级估计，其口径包含分数整体平移引起的跨场景对变化；本节 \(3\times10^{-8}\) 只计同场景对通道，是下界。**两个估计都比 pooled 噪声地板 0.001 小至少一个数量级以上**，故结论方向不受估法影响：pooled 端点在数值上不可能反映小场景的改善。

#### (d) 这一条的独立证据（因果四元组）

| 项 | 内容 |

| 唯一变量 | 判定与模型选择所用端点：macro ↔ pooled（数据集、架构、门控、loss、seed、设备全部相同） |
| 对照 run | **E7**（27K + 软路由 + **macro** 端点）vs **E8**（27K + 软路由 + **pooled** 端点） |
| 结果 | E7：\(\overline{\Delta}=+0.001881\)，4/4 seed 正，地板 0.001354，倍数 1.39 → **PASS**<br>E8：\(\overline{\Delta}=+0.001353\)，3/4 seed 正，地板 0.001022，倍数 1.32 → **INCONCLUSIVE**（同号条件不满足） |
| 证据文件 | `cache/macro_auc_27k/run_*.json`、`cache/macro_auc_27k/e5_decision.json` |
| 判定规则 | §0.5，跑前冻结于 [E5 预注册 §4](./20260815-0018-场景内泛化MoE长程矩阵预注册.md) |

逐 seed 对照（同一批 run，两个端点分列，遵守"端点不混表"）：

| seed | \(\Delta_{\text{moe}}\)（macro 端点） | \(\Delta_{\text{moe}}\)（pooled 端点） | macro/pooled |

（完整 4 seed 见 [E7 结论 §四](./20260816-1237-E7结论-27K场景内MoE首个work-case.md)；macro 端点的 Δ 系统性为 pooled 的 2–7 倍。）

**因此：换端点与换数据集是并列的必要条件。** 换数据集解决的是"尺子刻度不够细"（噪声地板 0.0113 → 0.00135）；换端点解决的是"尺子量的位置不对"（把 45.7% 权重压在 s1 内部 + 52% 权重给场景识别，改成 8 场景等权只测场景内排序）。两者缺一，判定都退回 `INCONCLUSIVE`。

### 3.3 换门控（软路由 → 硬路由 top_k=2）= **效应放大器（提高地板倍数）**

定义（§0 未覆盖，此处补足）：
- **软路由**：门控向量 \(g\in\mathbb{R}^K\)（由 `ScenarioRouter = Embedding(15,K)` 给出，零初始化）**全部 K=5 个专家都参与前向与反向**，输出按 \(g\) 加权；
- **硬路由 top_k=2**：取 \(g\) 中最大的 2 个分量，其余分量置零 → 每个场景**只有 2 个专家收到梯度**。参数量与软路由完全相同（激活稀疏，非参数稀疏），wall-clock 0.98×（**未省算力**）。

| 门控 | \(\overline{\Delta_{\text{moe}}}\)（macro，27K） | 地板倍数 | 同号正 seed | 判定 |
|---|---|---|---|---|
| 软路由（E7） | +0.001881 | 1.39 | 4/4 | PASS |
| 硬路由 top_k=2（E10） | +0.005012 | 3.70 | 4/4 | PASS |

- 二者的直接配对差（hard − soft，同 seed）= **+0.0031，4/4 seed 同号为正**。
- 机制假设：软路由下 5 个专家全部接收每个场景的梯度，专家参数被拉向所有场景的平均，特化被抑制；硬路由切断无关场景到专家的梯度通路，特化得以保留。
- 该假设的**可检验预测**：训练后每个场景的 dispatch 分布应显著偏离均匀（否则机制不成立）→ 由 E12 专家利用率诊断验证；若 top_k=1 进一步单调提升，则支持"梯度隔离越彻底越好"→ 由 E14 验证。
- 效果表述边界：这一步**只提高地板倍数（1.39→3.70），不改变判定枚举**（两者均为 PASS）。

### 3.4 删 ID 表 = **工程使能条件（不是收益来源）**

- 删掉后模型 551M→0.87M（÷634），单 epoch 从 20min 降到 3.4min（快 6 倍）；
- 这让 **4 seed × 多配置 × 多阶段**的矩阵变得可负担（E5+E7+E8+E10 共 80 run）；
- **但它不是收益来源**：E11 加回 ID 表后 MoE 收益依然 PASS（+0.0043，4/4 正）。
- 换句话说：删 ID 表让我们**跑得起实验**，不是让实验**出正结果**。

### 3.5 归因总结（精确版）

> 1. **数据集 1K→27K**：把 macro 噪声地板从 0.0113 降到 0.00135（÷8.4），使效应可被测量 —— **必要**（E5 反证）。
> 2. **判定端点 pooled→macro**：把 52% 的跨场景对权重与 45.7% 的 s1 内部权重，替换为 8 场景各 12.5% 等权，使测量对准 MoE 收益的作用位置 —— **必要**（E8 反证）。
> 3. **门控 软→硬 top_k=2**：把效应从 +0.001881 放大到 +0.005012（×2.66），地板倍数 1.39→3.70 —— **非必要但显著提高结论稳健性**。
> 4. **删三张高基数 ID 表**：使单 epoch 从 20min 降到 3.4min，让 80 run 的矩阵可负担 —— **工程使能条件，非收益来源**（E11 加回后仍 PASS）。

## 四、方法论教训（比结论本身更值钱）

1. **"没有效应"和"测不出效应"是两件事**。1K 上跑了两千块钱的实验全是 INCONCLUSIVE，
   过去被解读成"MoE 在这个任务上没用"；实际是**小场景 70 个正样本，统计上不可能测出**。
   → 新规矩：**开跑前先算噪声地板**（用 dense 臂跨 seed SD 或 Hanley-McNeil 标准误），
   若地板 > 预期效应，实验设计本身就是无效的，别花钱。

2. **主终点必须对准收益的作用位置**。pooled AUC 是"看起来最正统"的指标，
   但它对 MoE 的收益机制近乎不敏感。
   → 新规矩：**先问"这个改动的收益会出现在哪个子群/哪个维度"，再选端点**。

3. **参数占比不能推断瓶颈**。97.9% 的参数（ID 表）不仅不是瓶颈，加回来还有害。
   → 新规矩：判断瓶颈用容量对照（widened）或零成本诊断（曝光/OOV/消融），不看参数量。

4. **性能优化要先 benchmark 再动手**。本轮为加速 full-ID 写了 sparse embedding +
   SparseAdamW，实测 **dense AdamW 反而快 2.5 倍**（12.3ms vs 30.9ms），
   且 sparse 有"未访问行动量不衰减"的语义差异**无法严格对齐**，方案作废。
   → 新规矩：优化方案先跑 30 步 benchmark，再决定要不要写。

5. **公平性质疑要正面回应，不要绕开**。轻量模型上的结论天然会被问"是不是删东西删出来的"。
   花 20h 跑 full-ID 把它钉死，比在文档里解释十遍都有用。

## 五、当前最优配置与完整结论

**推荐配置**：轻量模型（去三大 ID 表，0.87M 参数）+ scenario-routed MoE(K=5, **硬路由 top_k=2**)

| 配置 | macro AUC | 参数量 |
|---|---|---|
| **轻量 + moe top_k=2** | **0.735388** ← 最优 | 869,750 |
| 轻量 + moe 软路由 | 0.732256 | 869,750 |
| 轻量 + dense | 0.730376 | 869,525 |
| full-ID + moe top_k=2 | 0.729206 | 551,317,700 |
| full-ID + dense | 0.724877 | 551,317,475 |

三层结论：
1. **MoE 有效**：Δ=+0.0050（轻量）/+0.0043（full-ID），两种规模下 4/4 seed 全正；
2. **收益来自路由**：参数守恒（+225）、优化器相同、frozen-router 哨兵 ≈0（−0.0003/+0.0001）；
3. **ID 表有害**：加回 5.5 亿参数 macro 降 0.0055，4/4 seed 负。

## 六、结论边界（登记，不得放宽）

1. 效应量级 +0.004~0.005 macro AUC（约 0.5 个百分点，相对 +0.7%），**方向可复现但绝对值小**，
   不得表述为"大幅提升"。
2. 口径限定：KuaiRand-27K、DCNv2、K=5、balanced loss、lr=1e-3、batch 10000、
   macro AUC（8 场景等权）、4 seed 同卡配对、early-stop 基于 macro valid。
3. **未验证条件计算收益**：top_k=2 是激活稀疏（5 个专家仍全算），wall 0.98x，**未省算力**。
4. **未验证专家是否真的分化**：训练后的 dispatch 分布尚未记录（见新实验计划 E12）。
5. 不跨数据集比较绝对 AUC；1K 的历史结论不外推到 27K，反之亦然。
