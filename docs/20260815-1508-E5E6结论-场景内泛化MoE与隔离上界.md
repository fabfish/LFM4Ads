## 一、E5：macro 端点下的 scenario-routed MoE 仍无稳定收益

设计：2 arch（dense / moe-K5）× 2 loss（pooled / balanced）× 4 seed = 16 run 主矩阵，
外加函数保持哨兵（2）、K 扫描（20）、lr 扫描（16）、84M 全 embedding 复核（4），共 58 run。
主终点 = 8 个场景（`TARGET_SCENARIOS`）等权 macro test AUC。

主结果（moe+balanced − dense+balanced）：

| seed | dense+bal | moe+bal | Δ_moe |
|---|---|---|---|
| 42 | 0.7278 | 0.7222 | −0.0056 |
| 123 | 0.7248 | 0.7231 | −0.0017 |
| 456 | 0.7311 | 0.7175 | −0.0136 |
| 789 | 0.7178 | 0.7200 | **+0.0022** |

- 跨 seed 变号，均值 **−0.0047**，实测噪声地板 **0.0113** → **判定 INCONCLUSIVE**。
- K 扫描（2/3/5/6/10/11，容量恒定）无单调趋势；lr 扫描（2e-4/1e-3/3e-3）无稳定正向；
  84M 全 embedding 复核（s42 +0.0065 / s123 −0.0029）同样变号。

### 关键哨兵：macro 端点的噪声是 pooled 的 11 倍

frozen-router MoE（gate 恒为 1）与 dense **在代数上完全等价**（K 个 `Linear(dim,dim/K)`
concat 后就是一个 `Linear(dim,dim)`），实测 macro 差却达：

| seed | frozen-MoE − dense |
|---|---|
| 42 | −0.0072 |
| 123 | −0.0039 |

**纯初始化随机性就产生 0.007 的 macro 差。** 这证明 macro 端点（8 场景等权）的噪声地板
是 0.011，而非 pooled 的 0.001。上一轮"macro 效应量放大到 0.01 级所以可测"的判断**只对了一半**：
效应放大了，但噪声同比例放大 11 倍，信噪比没改善。

## 二、E6：隔离上界 —— 连"完全隔离"都换不到收益

为判定"MoE 到底有没有空间"，测了参数隔离的**绝对上界**：给每个场景一个**完全独立**的模型
（零共享、独立 batch、独立早停、独立 valid 判据，一切设置偏向隔离方）。这是任何 MoE
（K=n_scenarios 硬路由）能表达的隔离的上限。

结果（每场景独立模型 vs 共享 dense，per-scenario test AUC）：

| 场景 | n_train | 独立 | 共享 | Δ |
|---|---|---|---|---|
| s0 | 1,929,564 | 0.7169 | 0.7139 | +0.0030 |
| s1 | 6,091,260 | 0.7346 | 0.7347 | −0.0000 |
| s2 | 324,817 | 0.7999 | 0.7977 | +0.0022 |
| s3 | 31,476 | 0.7403 | 0.7375 | +0.0028 |
| s4 | 704,966 | 0.7077 | 0.7189 | −0.0113 |
| s5 | 12,931 | 0.6627 | 0.6815 | −0.0188 |
| s6 | 141,545 | 0.7227 | 0.7322 | −0.0095 |
| s8 | 14,092 | 0.7720 | 0.7565 | +0.0154 |

**平均 −0.0020，4/8 胜出 = 抛硬币。** 完全隔离都赢不了 → MoE 参数隔离的收益上界**就是打平**。
这与容量结论（dense-widened 4× 收益 0）形成一致图景：**给 4× 容量收益 0，给完全隔离收益 0。**

## 三、真正元凶：小场景的测量噪声比任何效应大一个数量级

| 场景 | test 样本 | 正类数 | 实测 seed 波动 | AUC 理论 SE（Hanley-McNeil） |
|---|---|---|---|---|
| s0 | 230,796 | 26,933 | 0.0005 | 0.0027 |
| s1 | 803,191 | 350,643 | 0.0005 | 0.0007 |
| s2 | 40,645 | 14,997 | 0.0036 | 0.0033 |
| s3 | 3,404 | **70** | 0.0063 | **0.0524** |
| s4 | 95,506 | 51,921 | 0.0002 | 0.0022 |
| s5 | 1,833 | 368 | **0.0441** | 0.0246 |
| s6 | 21,600 | 3,171 | 0.0081 | 0.0079 |
| s8 | 2,065 | **71** | 0.0181 | **0.0498** |

**理论 SE 与实测 seed 波动逐场景吻合。** s3/s8 的 test 正类只有 **70 个**，AUC 统计噪声
0.02~0.05，而我们试图检测的效应只有 0.005~0.015 —— **噪声比信号大 3–10 倍**。

**结论**：KuaiRand-1K 在统计上不可能支撑 MoE 的 work case。不是调参不到位，是数据量不够——
小场景 70 个正样本，任何方法的改进都无法与噪声区分。继续扫 K/lr/loss/路由方式不可能突破
E6 给出的上界。

## 四、为什么 7B 通、这里不通（收口）

| | 7B LLM | KuaiRand-1K |
|---|---|---|
| regime | 数据 >> 参数，欠拟合 | epoch 2–4 即过拟合 |
| 容量 | 真瓶颈 | 4× 加宽收益 0 |
| 隔离 | 任务有真实函数差异 | 完全隔离收益 0（E6） |
| 每任务测量精度 | 充足 | 小场景 70 正样本，SE 0.05 |
