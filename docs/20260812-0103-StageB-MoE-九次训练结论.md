## 一、目标

Stage A 已证明：MoE 在 KuaiRand-1K **同容量**下对稠密**无 AUC 增益**（逐 seed 配对差跨 seed 变号，降级为「未稳定匹配」）。

Stage B 换更公平也更有信息量的问法：在 **same-active / same-total / same-latency** 公平比较下，
**低秩全维专家 + soft routing** 能否在「训练效率 / 路由结构 / 持续学习能力」上展现价值，而非堆 AUC。

> 失败判据（DRIVERS §十四）：若 Stage B 仍不能在公平比较下超过同名容量 dense，则**禁止 sparse scaling 叙事**。

## 二、环境与公平口径（测量口径说明）

| 项 | 取值 | 一致性 |
|---|---|---|
| 设备 | `cuda:0` 单卡独占 | 9 次串行，无并行 |
| seed | 42 / 123 / 456 | 三变体完全一致 |
| lr / beta2 | 1e-3 / 0.999 | 一致 |
| batch_size | 10000 | 一致 |
| max_epochs | 300（early-stop，patience=20） | 一致 |
| 加权 | `sample`（= pooled≈full-batch，见 Stage A） | 一致 |
| routing | `data`（DataRouter，仅 low-rank 变体） | — |
| 秩 r | 45 = dim//(2K)，使每个低秩交叉层 FLOPs `2*K*dim*r = dim²`，与 dense `Linear(dim,dim)` 同量级 | same-FLOPs |

> 容量对齐：低秩全维专家 MoE 每交叉层 = K 个 `Linear(dim,r)→Linear(r,dim)`，参数 `2*K*dim*r`；取 `r=dim/(2K)=45` → `2*4*360*45 = 129600 = dim²`，与 dense 交叉层完全同 FLOPs。DNN(2×) 与 head 二者一致 ⇒ **same-active / same-total / same-latency** 成立。

## 四、配对差与四态判定

**逐 seed 配对差（相对同 seed 的 same-FLOPs dense）：**

- `lrfd-fr` vs `sfd`：−0.0006 / −0.0003 / +0.0011 → 均值 **+0.0001** → 符号 `[-, -, +]` → **未稳定匹配**
- `lrfd-soft` vs `sfd`：−0.0004 / −0.0011 / +0.0003 → 均值 **−0.0004** → 符号 `[-, -, +]` → **未稳定匹配**

所有配对差的绝对值 ≤ 0.0011，远小于 KuaiRand-1K AUC 噪声尺度（Stage A 已量化同容量变体差异在 ≈ 噪声内）。
**结论口径（沿用 §十三）：禁止用跨 seed 均值差冒充「超过」；逐 seed 符号不统一 ⇒ 不能称稳定改进。**

**判定：匹配（差异在噪声内，无稳定增益，也无稳定损失）。**

**关键发现**：soft routing **确实学到了非平凡路由结构**（熵显著低于最大熵，专家权重随样本/层变化），
但这一结构**没有转化为 pooled / 按场景 AUC 增益**，也未带来 wall-clock 效率优势（三类变体单 run 训练时长均约 5–6 min，无差异）。

## 六、总体结论与失败关闭条件触发

在 **same-FLOPs 公平比较**下：

1. **AUC**：低秩全维专家 MoE（frozen 或 soft）与 same-FLOPs dense **匹配**，逐 seed 配对差符号不统一，不能在公平比较下稳定超过 dense。
2. **效率**：三类变体训练 wall-clock 无差异 ⇒ 无效率优势。
3. **结构**：soft routing 学到非均匀门控，但该结构无性能收益。

⇒ **触发 DRIVERS §十四 失败关闭条件**：Stage B 不能在公平比较下超过同名容量 dense，
**禁止 sparse scaling 叙事**。MoE 在 KuaiRand-1K 上无竞争力（容量对齐后 AUC/效率/结构均无优势）。

这与 Stage A 结论一致且独立加固：即便改用低秩全维专家 + 同 FLOPs 公平口径，MoE 仍无增益。
后续转入 **Stage C（路由比较 / 持续学习）** 或重新审视特征/路由归纳偏置，而非容量或 FLOPs 维度。
