🏗️ 模型架构

LFM4Ads 基于 DCNv2 (Deep & Cross Network v2)，360 维输入 → 3 层 Cross Network → 2 层 ReLU DNN → 15 维输出（8 个 tab 对应维），在 KuaiRand-1K 上预训练预测 CTR。

三级下游使用方式

预训练完成后，通过三种不同粒度的方式将 backbone 知识迁移到下游任务：

Feature Usage 特征级

冻结预训练 backbone，取中间 Cross Representation (CR) 作为特征增强。两种融合方式：gate（门控加权 sigmoid）和 concat（直接拼接）。

Module Usage 模块级

加载预训练权重的前 k 层 Cross Network 和 Embedding，其余层随机初始化后重新训练。k 从 0 到 6。

Model Usage 模型级

用预训练 backbone 输出作 Item Representation (IR)，与新训练的 User Representation (UR) 做内积预测。知识迁移粒度最粗。

📊 数据集：KuaiRand-1K

快手真实推荐数据，约 1000 名用户 的 3 个月互动日志，含 8 个下游场景（tab），每个场景为快手 App 内不同入口页面的用户行为分布，构成独立的子任务。

🚀 快速开始

# 环境配置
conda create python=3.13 -n LFM4Ads
conda activate LFM4Ads
pip install torch -i https://download.pytorch.org/whl/cu121
pip install torcheval tqdm pandas pyarrow matplotlib

# 下载数据
wget https://zenodo.org/records/10439422/files/KuaiRand-1K.tar.gz
tar -xzvf KuaiRand-1K.tar.gz
python dataset.py

# 运行实验
python main.py cuda:0
