# GPU0 占位守护（fake load keeper）

日期：2026-08-12
主题：后台长驻守护，空闲后置位 10% 假负载，真实任务来了让位

## 目标
在 GPU0 空闲足够久后，启动一个只占 ~10% GPU 利用率的“假计算程序”，保持卡处于被占用状态（避免被调度器/集群回收）；一旦有真实 GPU 任务挂上，立刻停掉假程序让位。

## 实现
- `scripts/gpu_keeper.py`：主程序。默认以“监控态”运行，用 `nvidia-smi` 轮询 GPU0 的计算进程与利用率（监控主进程不依赖 torch，轻量）。需要假负载时，`subprocess` 拉起自身 `--fake` 子进程，子进程用 torch 做小矩阵乘，以 10% 占空比循环。
- `scripts/start_gpu_keeper.sh` / `scripts/stop_gpu_keeper.sh`：长驻后台启动/停止（基于 `setsid nohup`，退出 shell 不中断）。
- `scripts/gpu-keeper.service`：systemd 单元（当前机器无 systemd，留作在 systemd 主机上使用）。

## 行为（默认）
1. GPU0 连续空闲（`IDLE_THRESHOLD_S`，默认 1200s=20min）无真实计算进程 → 启动假程序。
2. 假程序运行 `FAKE_DURATION_S`（默认 1200s=20min；设 0 = 一直跑到真任务出现）。
3. 假程序运行期间，若 GPU0 出现“其他”计算进程（真实任务）→ 立即终止假程序并让位。

## 配置（环境变量，可选）
| 变量 | 默认 | 含义 |
|---|---|---|
| `GK_GPU_ID` | 0 | 物理 GPU 序号 |
| `GK_TRIGGER` | idle | idle=空闲这么久后启动；busy=被真实任务占用这么久后启动 |
| `GK_IDLE_THRESHOLD_S` | 1200 | 空闲/占用判定时长（秒） |
| `GK_FAKE_DURATION_S` | 1200 | 假程序时长（秒）；0=跑到真任务出现 |
| `GK_POLL_S` | 10 | 轮询间隔（秒） |
| `GK_TARGET_UTIL` | 100 | 目标 GPU 利用率（%） |

> 注意：本机 `nvidia-smi` 序号与 torch `cuda:{id}` 默认一致（均未设 `CUDA_VISIBLE_DEVICES`）。若设了该变量需自行核对映射。

## 启动方式
```bash
# 长驻后台（无 systemd 时）
bash scripts/start_gpu_keeper.sh
# 调参示例：空闲 5 分钟即启动、假程序一直跑到真任务出现
GK_IDLE_THRESHOLD_S=300 GK_FAKE_DURATION_S=0 bash scripts/start_gpu_keeper.sh
# 查看日志
tail -f logs/gpu_keeper.log
# 停止
bash scripts/stop_gpu_keeper.sh
```

## 重启自愈（可选）
当前机器无 systemd，但有 `crond`。如需开机/重启后自动拉起，可加 `@reboot` 任务到用户 crontab：
```cron
@reboot sleep 30 && cd /root/Documents/Lfm4ads && setsid nohup python3 scripts/gpu_keeper.py >> logs/gpu_keeper.log 2>&1 &
```
（集群节点上 `@reboot` 是否生效取决于 crond 是否随节点启动；更稳妥的是放进节点的开机脚本。）

## 验证（2026-08-12 冒烟）
- 用小阈值跑监控：空闲 3s 后成功启动假程序（pid 正确）。期间 GPU0 出现一个瞬态计算进程，守护立即识别并让位停止 → “真任务来了就停”逻辑成立。
- 单独跑 `--fake` 12 秒：GPU0 利用率稳定采样 9% / 9% / 9% / 11% / 10% / 9%，符合 ~10% 目标；`kill` 后可正常退出，无残留。
- 清理后：GPU0 回到 0% / 0 MiB，无 compute-apps，无 `gpu_keeper` 进程。

## 后续 backlog
- 若需要“持续占位防回收”，将 `GK_FAKE_DURATION_S=0`（假程序一直跑到真任务出现），而非默认 20 分钟。
- 多卡可在 `GK_GPU_ID` 分别起多个实例。
- 若迁移到 systemd 主机，用 `scripts/gpu-keeper.service`（`systemctl --user enable --now gpu-keeper`）。
