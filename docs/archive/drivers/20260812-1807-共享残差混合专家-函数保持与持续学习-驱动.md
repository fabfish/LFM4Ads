## 1. 本轮唯一获授权范围

本轮不直接启动完整持续学习、shared LR、router LR 或 sparse scaling。授权链固定为：

1. `Function-Preserving Dense-to-MoE Upcycling Gate`（G1，无长程训练）；
2. `Learning-Rate Semantics Invariant Gate`（G2，CPU smoke）；
3. G1/G2 全部 PASS 后，执行 `Specialist-Only Continual Adaptation Screen`（G3，24 trials）。

后续 `Shared-Path Necessity Gate`、`Blockwise Learning-Rate Allocation Gate`、完整 baseline matrix、alignment-aware 消融及 sparse scale-out 均为 `blocked`。只有 G3 机器判定 PASS 才能另立驱动和 authorization，不允许低端执行模型自行扩展矩阵。

## 2. 冻结架构

每个 Cross 层使用：

\[
m(h)=E_{shared}(h)+\sum_{e=1}^{K}p_e(h,s)R_e(h),
\qquad h^+=h+x_0\odot m(h).
\]

- `E_shared`：逐位复制同 seed dense checkpoint 的 Cross Linear；
- `R_e`：低秩全维 residual specialist，`down: 360→45`、`up: 45→360`；
- `up.weight/up.bias` 严格零初始化，故初始 residual 为零；
- `K=4`，本轮 `p_e=1/K`，全部专家参与前向，router 严格冻结；
- `residual_scale=1`，不使用可学习 allocation gate；
- Sparse embedding、两层 DNN、shared Cross 全部从 dense 复制；
- dense 15 行 head 转为 15 个独立 `Linear(360,1)`，逐位复制，防止 AdamW 对非活动旧行施加 weight decay。

函数保持不变量：

\[
f_{shared\ residual\ MoE}(x)=f_{dense}(x)
\]

在 G1 通过前，禁止训练。

## 3. G1/G2 预注册阈值

### 3.1 G1：Function-Preserving Dense-to-MoE Upcycling Gate

对 seeds `42/123/456` 的 `cache/vanilla_from_scratch_seed{seed}.pt`，固定 validation 前 1024 样本：

| 检查 | PASS 阈值 |
|---|---:|
| shared 参数复制 | 逐位相等 |
| specialist up projection | `max_abs=0` |
| frozen router | 每项逐位等于 `1/K` |
| logits | `max_abs_error ≤ 1e-6` |
| BCE loss | `abs_error ≤ 1e-7` |
| probe pooled AUC | `abs_error ≤ 1e-12` |

任一 seed 失败：G1=`BLOCKED`，不得执行 G3。

### 3.2 G2：Learning-Rate Semantics Invariant Gate

必须同时通过：

1. 固定 pre-Adam 梯度缩放在稳定 Adam 下实际步长比接近 1，而不是缩放倍率；
2. 独立 parameter-group LR 的实测 update ratio 与 LR ratio 一致；
3. 非活动 task head step 后逐位不变；
4. 非拥有 specialist step 后逐位不变，当前 specialist 必须发生更新；
5. sample-weighted task gradient 与 full-batch gradient 误差 `≤1e-7`；
6. 标准 BWT 使用 `A[T-1,j]-A[j,j]`，测试夹具结果必须为 `-0.1`。

证据：`cache/audit/shared_residual_continual/shared_residual_experiment_invariants.json`。该文件不可覆盖。

## 4. G3 固定矩阵

### 4.1 任务、顺序与种子

- order A：`scenario-0 then scenario-3`；
- order B：`scenario-3 then scenario-0`；
- seeds：`42 / 123 / 456`；
- 每个 task 固定训练 `2 epochs`，禁用 early stopping；
- batch size `10000`，AdamW `betas=(0.9,0.999)`，`weight_decay=0`；
- 所有实验臂的当前 task-head LR 固定为 `5e-4`；三档扫描只改变 specialist LR；
- 每个 scenario 单独训练，因此每个 optimizer step 的目标就是该 task 的 per-sample mean BCE；
- 每学完 task 后评估 order 中全部任务，形成完整 2×2 A matrix。

### 4.2 实验臂

1. `Task-Head-Only Adaptation`：仅当前独立 task head；LR=`5e-4`；
2. `Specialist-Only Adaptation`：当前 task head + 当前 task 拥有的 specialist；
3. specialist LR：`2e-4 / 5e-4 / 1e-3`。

本轮 task→expert 归属只由 scenario identity 决定，不依赖训练顺序。shared/backbone/router、旧 task head、非拥有 experts 严格冻结。

总数：

\[
2\ orders\times3\ seeds\times(1\ head\ baseline+3\ specialist\ LR)=24\ trials.
\]

## 5. 双卡与失败隔离

固定 `seed_device_map`：

| seed | device |
|---:|---|
| 42 | `cuda:0` |
| 123 | `cuda:1` |
| 456 | `cuda:0` |

- 同 seed 的全部 arm/LR/order 固定同一物理卡；
- 每张卡同一时刻只运行一个 trial；不同 seed 可跨卡并行；
- 每个 trial 是独立进程、独立 immutable run directory、独立 log；
- 单 trial 非零退出后登记 `failed_trials`，调度器继续该卡队列的下一项；
- 已存在 `done/blocked/running/corrupt` 目录均不覆盖；失败重试必须另立驱动，不删除证据；
- source/dataset/dense-checkpoint/driver/auth hash 在矩阵开始冻结，并与 G1 报告逐 seed 绑定；执行中变化则矩阵 `blocked`；
- 一键入口使用启动锁和全生命周期运行锁，禁止并发启动第二个正式矩阵；矩阵级失败会终止并等待所有活跃 trial。

## 6. 主指标与 G3 判定

主终点：标准 BWT。保护终点：Learning Accuracy、average forgetting、worst-task forgetting。Forgetting 采用标准正向定义 `max historical AUC - final AUC`，正值表示遗忘，worst-task 取最大值。

对每个 specialist LR，相对同 seed、同 order 的 head-only baseline：

1. 两个 order 各自的 3-seed BWT paired differences 必须全部 `>0`；
2. 每个 order 的 mean paired BWT improvement 必须大于该 order head-only baseline 的 3-seed 极差；
3. Learning Accuracy paired differences 不得在任一 order 三 seed 全部 `<0`。

- 至少一个 LR 同时满足两 order：G3=`PASS`，仅解锁另立 `Shared-Path Necessity Gate`；
- 所有 BWT paired differences 均 `≤0`：`FAIL`；
- 其余：`INCONCLUSIVE`；
- 缺 trial、失败、hash/公平性异常：`BLOCKED`，不得把部分结果解释为方法结论。
