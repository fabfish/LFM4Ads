## 1. 背景与动机

训练只占 ~4GB / <40% util（双卡各 98GB，富余 ~94GB），根因是 DCNv2 模型极小
（non-Sparse ~65 万参数，99.2% 是 embedding 表）+ `batch_size=10000` 计算量小 +
`train_moe` 逐 scenario 串行化。为在不改动 D20（rx-only，进行中）且**严格不改 AUC**
的前提下填满 GPU，本批做两件事：

1. **零风险提速**：`train.py` 两 DataLoader 加 `pin_memory=True`、主进程搬运改
   `.to(device, non_blocking=True)`，新增 `LFM_NUM_WORKERS`（默认 10 保持 D18/D19/D20
   可复现）。传输机制改变但计算图与数值顺序不变 → AUC 逐位一致
   （张量等价性测试 `equal=True, max abs diff=0` 已验证）。
2. **并发填充**：用 `scripts/launch_pack.py` round-robin 双卡、每卡 3 job，并发跑
   两个互相独立的研究课题。

## 2. 并发实验设计（口径）

| 研究 | job | 入口 | 关键参数 | 目的 |
|------|-----|------|---------|------|
| **D6 MoE V2 shared 验证** | `d6_v2_s42 / s123 / s456` | `main_moe_v2.py` | `--shuffle` × 3 seeds | 验证 V2（shared expert + top-k）相对 V1 的提升，多 seed 给方差 |
| **backbone 选择标准** | `bb_v1_s42 / s123` | `main_moe.py` | `--shuffle --skip-downstream` × 2 seeds | V1 预训练 AUC（Rx/All）基准 |
| **backbone 选择标准** | `bb_v2_s42 / s123` | `main_moe_v2.py` | `--shuffle --skip-downstream` × 2 seeds | V2 预训练 AUC（Rx/All）基准 |

> ⚠️ **vanilla 作为第三 backbone 的基准**已由历史 `cache/dcnv2_vanilla.pt` 提供
> （D8/D0 已产 `test_auc_all`）。本批只对 V1/V2 补 `--shuffle` 多 seed，避免重复跑
> vanilla。后续在 §4 汇总三 backbone 的 Rx/All AUC 建立「下游该选哪个 backbone」判据。

**方法学约束遵守**：
- D20（rx-only）的两个在跑 job **未动**，本批 job 与 D20 同属不同研究课题，并发不违反
  `AGENTS.md` §2 串行口径（串行为"横向变体"约束，跨课题并发允许）。
- 并发 job 设 `LFM_NUM_WORKERS=4`（384 核足够，防止 worker 扇出）。
- D20 的其它臂（full / freeze-dnn-head）属 D9-A 冻结强度横向对比，必须单卡独占串行，
  **不**混入本批并发 → 见 §5 `cache/d20b_chain.sh`（rx-only 结束后补跑）。

## 3. 启动命令（可复现）

```bash
# 零风险提速已提交：train.py pin_memory + non_blocking + LFM_NUM_WORKERS
# 并发启动（后台，D20 不动）：
setsid nohup python scripts/launch_pack.py \
    --devices cuda:0 cuda:1 --max-per-device 3 --num-workers 4 --monitor-interval 300 \
    -- \
    "d6_v2_s42|main_moe_v2.py|--shuffle --seed 42 --tag d6_v2_s42" \
    "d6_v2_s123|main_moe_v2.py|--shuffle --seed 123 --tag d6_v2_s123" \
    "d6_v2_s456|main_moe_v2.py|--shuffle --seed 456 --tag d6_v2_s456" \
    "bb_v1_s42|main_moe.py|--shuffle --seed 42 --tag bb_v1_s42 --skip-downstream" \
    "bb_v1_s123|main_moe.py|--shuffle --seed 123 --tag bb_v1_s123 --skip-downstream" \
    "bb_v2_s42|main_moe_v2.py|--shuffle --seed 42 --tag bb_v2_s42 --skip-downstream" \
    "bb_v2_s123|main_moe_v2.py|--shuffle --seed 123 --tag bb_v2_s123 --skip-downstream" \
    > cache/lfm4ads_launch_pack.log 2>&1 < /dev/null &
```
