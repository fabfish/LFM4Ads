## 2. 五条结论的审计判定

1. **稠密 sample-weighted ≈ full-batch（0.780663 vs 0.780677）** —— **成立**。可称「数值等价」（|Δ|≤4e-5）。
2. **恢复率 R=0.997** —— **拆分为两个不可混称的指标**。精确三 seed 均值给出
   `R_gain=(sample_mean-equal_mean)/(full_mean-equal_mean)≈0.999`；同 seed 配对给出
   `R_resid=1-mean_seed|sample_seed-full_seed|/(full_mean-equal_mean)≈0.992`。
   Stage A 在两种口径下均 PASS，但文档必须同时写公式、数值和配对来源。
3. **MoE 稳定匹配稠密** —— **需降格**。frout / nrout / pshr 三组相对同 seed dense 的逐 seed 配对差均跨 seed 变号，
   不能称「等价/匹配」，应改为「未稳定匹配、存在 seed 级反转」。
4. **V2 frozen 仍注入随机 gate noise** —— **错误（已修复）**。见 fix#4。
5. **V1 data router=1/K 与 scenario router=1 一致（统一恒等初始化）** —— **成立（破口）**。已加
   `DataRouter.gate_scaling` 数值对齐路径（默认 1.0 不变以保既有训练）；docs 去掉「统一恒等」强宣称。

## 3. 代码 / 脚本修复（fix #1–#5）

### fix#4 — V2 冻结路由器噪声（最严重）
- 根因：`model.py` `CrossExpertLayerV2._gate` 中 `noise = F.softplus(noise_logits) + 1e-2`；
  `freeze_routers` 只把 `w_noise` 清零，但 `w_noise=0` 时 `softplus(0)+1e-2≈0.703` 仍作为噪声注入，
  使「冻结」并非严格零噪声。
- 修复：
  - `model.py` `CrossExpertLayerV2.__init__` 新增 `self._router_noise_enabled = True`；
  - `CrossExpertLayerV2._gate` 门控条件加 `and self._router_noise_enabled`；
  - `run_moe_pretrain_from_scratch.py` `freeze_routers` 在冻结 `w_gate/w_noise/router` 后
    额外置 `layer._router_noise_enabled = False`（V1 `CrossExpertLayer` 无噪声，本就确定）。
- 验证：`scripts/verify/verify_router_invariants.py` 现 PASS（冻结 V2 门控恒 uniform=1、零噪声、可复现）。

### fix#5 — V1 router 不变量
- `model.py` `DataRouter` 新增 `gate_scaling`（默认 1.0）；`gate_scaling=K` 时 uniform 输出全 1，
  与 `ScenarioRouter(softmax*K)` 对齐，提供「统一恒等初始化」的数值路径。默认 1.0 不影响既有训练。

### fix#2 — 恢复率精确化
- `scripts/summarize/summarize_sample_weighting_gate.py`：按 seed 登记 full-batch dense 精确锚点；分别报告
  `R_gain` 与同 seed 配对的 `R_resid`，禁止把单一 full 均值重复用于 residual 计算。

### fix#3 — 路由器不变量门控
- `scripts/verify/verify_scenario_loss_weighting.py`：新增 `assert_router_invariants()`，作为 Stage A 前置门控；
  失败即写 `equ_swg_status.json={"status":"fail"}` 并退出非零，阻止铺开。

### fix#1/#6 — 可追溯性
- `scripts/matrix/run_sample_weighting_gate.py`：manifest provenance 新增 `router_semantics`
  （`freeze_router=True` → 冻结零噪声；否则 noisy_routing），记录 `run_moe_pretrain_from_scratch.py` 实际解析出的语义。
- 新增 `.codebuddy/skills/lfm4ads-experiment-audit-planner/scripts/verify/audit_experiment_bundle.py`：
  抽取单 run 的 {seed, method, weight, device, freeze_router, router_semantics, runlog 头尾,
  summary, swg 不变量, provenance} 打包成 JSON，供审计留痕。

## 5. 结论边界 6 规则（启动后不得擅自改判更弱）

1. 稠密 sample≈full：可称「数值等价」（|Δ|≤4e-5）。
2. 恢复率：分别称 `R_gain≈0.999` 与同 seed `R_resid≈0.992`，不得合并为单一 R。
3. MoE 非稳定匹配：称「未稳定匹配、存在 seed 级反转」，不称「等价/匹配」。
4. 冻结路由器：修复后称「零噪声、恒均匀」，不得再宣称「等价/匹配」（见规则 3）。
5. V1 data/scenario 不一致：称已破「统一恒等」强宣称，已补 `gate_scaling` 对齐路径。
6. 任何「零噪声/等价/恢复率」类结论须附 `scripts/verify/verify_*` 可复现输出，R 用精确锚点。
