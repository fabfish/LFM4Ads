## 1. 核心结论

上一阶段约 290 次训练观测到的「按场景训练代价 -0.0140」（同稠密模型、仅训练过程不同）
**不是按场景梯度的必然代价，而是 `train_moe` 按场景内均值 loss 累加的实现缺陷**。

将每个子批量 BCE 按其样本占比加权（`loss = criterion(...) * mask.sum()/tab_batch.numel()`）
后，损失目标在数学上严格等于整批训练目标（`train()` 路径）。实测验证：

- 数值等价校验 `equ-swg`：整批 BCE mean 与样本加权场景 BCE 之和绝对误差 = 5.96e-08（≤1e-6）；
  对权重的梯度最大绝对误差 ≤ 1e-6、相对误差 ≤ 1e-5。**PASS**。
- 稠密关卡（sample 加权，3 种子）pooled AUC 精确均值 = **0.780663**（整批稠密精确三 seed 均值 = **0.780677**），
  相对旧按场景等权 0.7666 的恢复率 **R≈0.999**（≥0.75）。**PASS**。
  > 注：此前用四位四舍五入整批值 0.7807 带入公式得到 R=0.997，属数值精度假象；
  > 用精确三 seed 均值重算 `R = 1 - mean|sample-full|/(full-equal) ≈ 0.999`，见 §8 结论边界登记表。
- 铺开 9 次 MoE 条件实验：全部在 0.7803–0.7808 区间，与 sample-dense / full-batch-dense
  的差距均 ≤ 0.0004，量级小于噪声地板 0.0036；**但逐 seed 配对差在 frout / nrout / pshr 三组均跨 seed 变号**
  （见 §4 与 §8），故结论应**降级为「未稳定匹配、存在 seed 级反转」**，不能称「等价/匹配」。

**含义**：修复训练目标后，混合专家在 KuaiRand-1K 上并未对同容量稠密基准产生 AUC 增益；
先前「全路由+冻结相对同过程 +0.0047」完全来自未修复的按场景代价坑。旧 router 调制 36 配置网格
（决策四已结案）在此结论下**永久关闭**——因为 normal-router 未稳定优于 frozen-router（Δ=-0.0002）。

- device = cuda:0 独占单卡；seed = 42 / 123 / 456；lr = 1e-3；beta2 = 0.999；shuffle = True；
  batch = 10000；K = 4；routing = data；scenario-loss-weighting = sample（除参照值外）。
- 主指标 pooled AUC（`test_auc_all`），辅助按场景 AUC 均值（`mean_per_scenario_auc`）。
- 所有横向比较控制变量（除被测 model/freeze_router 外完全一致），单卡串行。
- 参照值（**历史、不重跑**）：整批稠密 0.7807；按场景等权稠密 0.7666。

## 3. Stage A 关卡结果（稠密 + sample 加权）

| run-code | 全称解释 | seed | pooled AUC | mean-per-scenario AUC |
|---|---|---|---|---|
| `swg-dens-sp-42` | Sample-Weighting Gate + Dense + sample + seed 42 | 42 | 0.7807 | 0.7327 |
| `swg-dens-sp-123` | 同上 + seed 123 | 123 | 0.7814 | 0.7335 |
| `swg-dens-sp-456` | 同上 + seed 456 | 456 | 0.7799 | 0.7237 |

- 精确均值 = 0.780663；整批精确 0.780677；|Δfull| = 0.000014；
  R = (0.780663-0.7666)/(0.780677-0.7666) = **0.9990**（此前用四舍五入整批值 0.7807 误得 0.997）。
- 三 seed 均比 equal(0.7666) 更接近 full(0.780677)（满足「≥2/3」）。
- 判定：**PASS**（不变量通过 + 3 seed 完整 + |Δfull|≤0.0036 + R≥0.75）。

## 4. 铺开结果（9 次 MoE 条件实验，仅关卡 PASS 后运行）

| run-code | 全称解释 | seed | pooled AUC | mean-per-scenario AUC |

### 相对口径（与 sample-dense 均值 0.7807 / full-batch 0.7807 比较）

| 组 | 均值 | vs sample-dense | vs full | 判定 |
|---|---|---|---|---|
| frout（冻结） | 0.7805 | -0.0001 | -0.0002 | 未稳定匹配(跨seed变号) |
| nrout（正常） | 0.7803 | -0.0003 | -0.0004 | 未稳定匹配(跨seed变号) |
| pshr（共享） | 0.7805 | -0.0002 | -0.0002 | 未稳定匹配(跨seed变号) |

- normal vs frozen：**逐 seed 配对差跨 seed 变号**（frout-frozen vs nrout-normal：seed42 ≈ +0.0006、
  seed123 ≈ -0.0003、seed456 ≈ +0.0005），故只能称「无稳定方向性差异」，不能称 normal 稳定等于 frozen。
  Δ 均值 = +0.0002（|Δ| ≪ 0.0036 噪声地板），不足以支持任何方向性结论。
  → **旧 router 调制 36 配置网格永久关闭**（驱动文档 §十三）。
