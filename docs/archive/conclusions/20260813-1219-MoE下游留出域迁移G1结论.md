## 1. 目标

检验预注册主张：目标场景 `[2,5,6]` 标签完全不进入预训练、每 target 固定 4096 总标注（3072 fit + 1024 validation）、下游可训练参数近似匹配时，冻结的低秩全维 MoE 专家库（`K=4,r=45`）仅适配 router+binary head，能否跨 seed 方向一致地优于冻结 dense backbone 的 rank-2 residual adapters+binary head。

## 2. 环境与口径

- source scenarios `[0,1,3,4,8]`，held-out targets `[2,5,6]`，seeds 预注册 `[42,123,456]`。
- 源域预训练：batch 10000、AdamW lr=1e-3、pooled per-sample BCE、validation AUC 早停。
- 下游四 arm：`dense-head`(361) / `dense-adapter-r2`(4681) / `moe-head`(361) / `moe-router`(4693)；batch 512、AdamW lr=5e-4、max 50 epoch、validation 早停(patience 5, δ=1e-4)。
- 设备：全部 cuda:1；同 seed 四 arm 同设备。
- 本结论只覆盖 **seed 42**，因 G1 门控失败，矩阵按预注册协议停止，未扩 seeds 123/456。

## 3. 源域预训练质量审计（seed 42）

| 模型 | source test AUC | source best val AUC |
|---|---|---|
| dense | 0.7771 | 0.7757 |
| moe | 0.7778 | 0.7766 |

dense 与 MoE 源域表现几乎相同（差 0.0007），两个 backbone 以相同口径完成源域预训练。

## 5. 判定

**G1 feasibility gate FAILED → 矩阵按协议停止，未运行 seeds 123/456。**

- 预注册通过条件（三个 target 的 validation `moe-router − dense-adapter-r2 > 0` 且 `moe-router − moe-head > 0`）仅 t2 满足，t5/t6 均不满足。
- 按驱动 §7「G1 只控制是否扩矩阵，不产生正式优势结论；失败即停止，不扫描 LR/K/r/target」，本次**不产生正式 G2 PASS/FAIL 结论**；路线在 G1 关闭。

## 6. 分析与解释

1. **router-only 适配未稳定胜过 dense rank-2 adapter。** validation 上 moe-router 只赢 t2（且仅 +0.0003，噪声级），t5/t6 均输给 dense-adapter-r2；test 上赢 2/3 但 t2 大输 −0.0072，方向不跨 target 一致。

2. **路由适配的增益本身很弱。** `moe-router − moe-head`（test）：t2 −0.0010、t5 +0.0152、t6 +0.0005，仅 t5 有明显正增益；说明"冻结 MoE 表示之上加 router 适配"在多数 target 上不产生收益。

3. **dense rank-2 adapter 是更强且更一致的适配器。** `dense-adapter-r2 − dense-head`（test）：t2 +0.0147、t5 +0.0118、t6 −0.0051，在 2/3 target 上明显正增益。Δ_adaptation 在 t2 为 −0.0158，即 dense 适配的相对增益远大于 MoE 路由适配。

4. **目标域异质性是决定性的。** t2（最大训练域）是 MoE router 相对 dense adapter 最差的地方；t5（最小训练域 12931 行）是 router 唯一明显获益处。这正是"稳定、可复现"标准所不允许的 target 依赖。

5. **与前序结果一致。** 这是 MoE 路线第 4 次未形成稳定优势：static same-FLOPs（FAIL）、TCMR（INCONCLUSIVE）、共享残差 G3（INCONCLUSIVE）、本次下游 router-only 迁移（G1 失败）。MoE 路由机制在 KuaiRand-1K 上反复未能对 dense 基线产生方向一致、可复现的增益。

## 7. 完整性审计（未发现异常）

- G0/G0-final 审计 PASS；四 arm 可训练参数 361/4681/361/4693（主比较差 12，0.26%）。
- source/target 行互斥；9 组 3072/1024 + test 索引 SHA-256 冻结。
- dense 两 arm 冻结参数哈希一致；moe 两 arm 的冻结哈希差异来自 router 是否可训练（`moe-head` 冻结 router、`moe-router` 训练 router），且二者来自同一源 checkpoint（ckpt hash 一致）——符合预期，非冻结漂移。
- 12/12 trial 完成，无失败。

**已知局限（透明声明）**：trial 内只记录训练前冻结哈希；训练后 bitwise 不变由构造保证（`requires_grad_(False)` + 优化器只含可训练参数），未在每 trial 训练后重算一次哈希。建议后续 runner 在训练后追加一次冻结哈希校验。

## 8. 结论（可表述边界）

在 KuaiRand-1K 固定 source `[0,1,3,4,8]`、held-out targets `[2,5,6]`、4096 总标注、seed 42、约 4.7k 下游可训练参数的协议下，**未发现 MoE router-only 适配方向一致地优于 dense rank-2 adapter 的证据**；G1 可行性门控失败，路线关闭。

不得据此表述为：MoE 普遍劣于 dense、或所有 MoE 下游迁移无效。仅支持"该固定协议下未建立 MoE 下游留出域迁移优势"。
