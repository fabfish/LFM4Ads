## 一、判定结论

**关卡判定：INCONCLUSIVE（不可晋级）。**

主候选 **DATR**（Data-and-Task Routing）相对两个主锚点 **FUR**（Frozen Uniform Routing）、**DOR**（Data-Only Routing）的同 seed 配对 pooled AUC 差，在 3 seed（42 / 123 / 456）之间**跨正负变号**，不满足 PASS 所需的「三 seed 严格同向」。

**稳定性额外门槛也未达**：DATR 对两锚点的平均配对差均小于各自锚点三 seed 极差（噪声地板），故 `stable_improvement_claim = NOT_SUPPORTED`。

与上游 Stage B 结论一致：低秩全维 MoE 相对同 FLOPs dense 跨 seed 变号、竞争性主张 FAIL；本关卡同样只能称「未稳定超过」，不能称「匹配 / 等价 / 稳定改进」。

## 五、保护指标

- **路由塌缩**：`gate_decision.collapsed_runs = []`。DATR 三层 mean layer entropy = 1.133 / 1.016 / 1.085，远高于塌缩阈值 0.25×ln(4)=0.347；最大 mean gate 未触 >0.95、最小未触 <0.01。无塌缩。
- **macro AUC 系统性恶化**：`systematically_degraded_scenarios` 两锚点均为空。DATR−FUR macro Δ = [−0.00254, +0.00115, +0.00045]，DATR−DOR macro Δ = [−0.00137, −0.00145, +0.00406]；逐 seed 均末出现三 seed 全负。
- **逐场景系统性恶化**：无某正式报告场景对锚点三 seed 全负且平均下降 ≥0.001。

## 六、次级模式（仅解释，不可替换主终点）

- **TOR**（Task-Only Routing）：soft task-expert 互信息仅 0.0005–0.0007 nats，路由几乎不靠任务标识分离专家；pooled AUC 与 FUR 同量级（0.7796–0.7810）。
- **DATCR**（Data-and-Task Consistency Routing，加对称 KL λ=0.01）：pooled AUC（0.77995 / 0.78157 / 0.78085）与 DATR 几乎重合，一致性项未带来可分辨增益。

两者均在 `secondary_modes_cannot_replace_primary_endpoint` 中列出，不用于决定晋级。
