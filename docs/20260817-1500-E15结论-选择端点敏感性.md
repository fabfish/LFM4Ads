## 一、结论一句话

**把"训练中按哪个 valid 指标选 epoch"（模型选择端点）从 macro 换成 pooled，MoE 相对 dense 的收益方向不变（4/4 seed 同号正），但统计强度从 3.70 倍地板掉到 1.05 倍地板——方向稳健、强度不稳健。** 预注册结局 = **A（两种选择规则都 PASS）**，但"稳健"二字须按 §三 收窄。

## 三、必须诚实登记的限定（"稳健"的分量）

1. **方向稳健，统计强度不稳健。** pooled 选择下 Δ 仍 4/4 同号正，但地板倍数从 3.70 → **1.05**，贴着噪声边界过线，属最脆弱的 PASS。
2. **pooled 选择同时做两件坏事**：
   - 压低效应：Δ 均值 0.005012 → 0.003478；
   - **放大噪声地板 2.4 倍**：0.001354 → 0.003307。
   机理：pooled 选出的 epoch 明显更晚（dense ep 11–20、moe ep 18–20，而 macro 选的是 ep 5–9），更靠近过拟合区，dense 臂 macro 的跨 seed 波动被放大。
3. **选择惩罚不对称**（test macro：pooled 选择 − macro 选择）：dense 均值 −0.002753，moe 均值 −0.004288（4/4 负）。moe 受的惩罚更大，故配对差也被压窄。
4. **这反过来强化方法论结论**：用 pooled 选 epoch 不只是"量错地方"，还会**压低效应 + 放大噪声**，两个方向同时削弱统计功效 → 支持"应以 macro 选 epoch"的既有决策。

## 五、对已有结论的更新

- **保留**：E10/E11 的 PASS 不受影响（由 test macro 配对差独立支撑，且 E15 复现哨兵 8/8 逐位一致）。
